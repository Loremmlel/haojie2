# 豪杰棋局 II · haojie2

一个可离线运行的同屏双人回合制战棋。React + TypeScript，独立规则引擎；**生产构建只生成一个 `dist/index.html`**，JavaScript、CSS、图标、棋子和音效均不依赖外部运行时资源。

## 直接运行

需要Node.js 22及npm。

```bash
npm ci
npm run dev
```

打开终端显示的本地地址，默认 `http://127.0.0.1:4173`。源码变更后会自动重建，刷新浏览器即可看到变化。

生成可分发的离线文件：

```bash
npm run build
```

把 `dist/index.html` 复制到任意位置，用现代浏览器打开即可对战；也可以作为静态页面放进现有网站。运行游戏不需要Node.js、数据库、API服务或联网。受管理浏览器可能禁止直接打开本地HTML，可改用本地HTTP服务或网站静态页面。

GitHub Actions成功运行后，`haojie2-single-html`产物中也包含同一份单文件成品。

## 怎么玩

苍穹方先手，赤焰方后手，两人轮流操作同一设备。每个回合开始随机召唤两张牌，随从必须当回合部署，法术可保留。选中棋子后，在侧栏选择移动、攻击或技能，棋盘会标出合法位置或目标。基地生命降至0的一方失败。

“新对局”可选择正式对局，也可载入预设阵型的演示局。正式对局从空棋盘开始；演示局可以直接体验攻击、击杀成长、反击、法术与悔棋。双方手牌公开，没有倒计时。

## 已实现

- **完整棋盘与棋子能力**：9×13棋盘、双方300血基地、26个召唤编号，以及3′、墓地和路障。包含2×2占位、蓄力、治疗、名刀、友伤转化、死亡反击、献祭、临时单位、策反与循环成长等特殊结算。
- **可读的操作反馈**：合法落点与攻击目标高亮、分步技能选点、剩余行动点、蓄力条、状态标签、战报、部署动画、移动过渡、弹道、爆炸、护盾、伤害数字与可选合成音效。
- **悔棋和对局保存**：最近60步完整撤销/重做，允许跨回合；包含随机数状态，不通过悔棋重新掷骰。自动本机保存、刷新恢复、JSON导出/导入。浏览器拒绝本地保存时会提示使用导出。
- **规则与图鉴**：29个图鉴条目，支持名称/能力搜索及随从、法术、变体分类。规则说明与实际棋子定义共用数据来源，显式列出规则歧义的解释。
- **桌面与手机布局**：桌面多栏、随视口高度调整棋盘；手机横向手牌和紧凑操作面板。棋盘支持方向键、Enter，悔棋支持Ctrl/⌘+Z，并尊重系统“减少动态效果”设置。

## 规则解释，需作者确认

原文有几个不能无歧义直接转为程序的地方，本版没有悄悄忽略：

1. 距离原式 `abs(c+d-a-b)` 暂按常见四向格距 `abs(c-a)+abs(d-b)` 实现。
2. 3′的攻击公式含异常字符，暂按 `max(0,40-5n)` 实现。
3. 回合、储存期限、名刀次数、分数移速/攻速、钩子落点、献祭方向和策反时序等，均有明确解释。

完整契约见 [规则说明](docs/RULES.md)，也可在游戏内“规则 → 本版本的规则解释与待确认事项”查看。调整这些解释时，应同时修改引擎行为测试和共用图鉴定义，而不是只改界面文案。

## 低耦合架构

```text
src/engine/       纯TypeScript规则、寻路、随机数、结算、历史与存档验证
src/ui/           React组件、分步选点、矢量视觉、CSS动画、合成音效
src/index.ts      对外导出的React组件和引擎API
src/main.tsx      独立页面挂载点
scripts/          单HTML构建和本地开发服务
tests/            规则行为测试、离线浏览器验收
docs/             规则契约与架构/嵌入说明
```

引擎不依赖React、DOM、网络或本地存储。对局使用 `applyCommand(state, command)` 产生新状态与事件，非法操作不修改输入状态。界面不自行扣血、扣行动或判胜负。

可以只导入 `src/engine`，也可以使用公开入口中的 `<HaojieGame />` 嵌入现有React/Next.js网站。组件支持 `initialState`、`storageKey` 和 `onStateChange`；详见 [架构与嵌入](docs/ARCHITECTURE.md)。

**当前不包含联网房间、AI对手、账号或服务端。** 将来联网时可复用此引擎，但仍须实现服务端权威状态、身份验证、重连和双方同意悔棋，不能把本地存档验证当成防作弊机制。

## 验证

```bash
npm run check        # TypeScript严格检查
npm test             # 棋子、回合、寻路、特殊结算、随机性和存档行为
npm run build        # 只生成一个HTML
npx playwright install chromium
npm run test:browser # 直接打开离线file://成品，实际操作桌面与手机界面
```

已有系统Chromium时，浏览器测试会优先使用 `/usr/bin/chromium`；也可设置 `BROWSER_PATH`。浏览器验收记录攻击、悔棋、存档、图鉴、手机无横向溢出、外部网络请求及未捕获异常，并输出截图和JSON报告至 `artifacts/`。

GitHub Actions执行完整检查并提供离线HTML、源码快照、验收截图。测试关注可观察行为，不使用大批整页像素快照来约束实现细节。

## 依赖与资源

运行时只使用React与ReactDOM。构建用esbuild，行为测试使用Node内置测试运行器和tsx，浏览器验收使用Playwright。依赖树由 `package-lock.json` 固定。

棋子、图标、棋盘装饰均由本项目的内联矢量/CSS构成，不加载图片或字体文件；音效由Web Audio生成。发行HTML保留已打包第三方运行时组件的许可证文本。
