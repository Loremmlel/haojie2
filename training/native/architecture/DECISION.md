# 连续训练与原生管线决策

## 训练方法

当前保留同席位连续短轨迹、bootstrap 与 V-trace，折扣为 1。奖励只来自真实终局：胜 +1、负 -1、平 0，其他转换为零。对手行动期间保留未决转换，连接到下一同席位决策。

这是针对长局、稀疏终局奖励、可持续有界管线的工程选择。终局训练也有成立的依据；本轮不做棋力或收敛比较。训练预算按实际消费单列。

- [IMPALA](https://arxiv.org/abs/1802.01561)：解耦 actor/learner，使用短轨迹和 V-trace 修正行为策略滞后。
- [GAE](https://arxiv.org/abs/1506.02438)：bootstrap 与完整回报之间存在偏差、方差取舍。
- [AlphaZero](https://arxiv.org/abs/1712.01815)：终局结果训练价值，另有搜索产生的策略监督。
- [SEED RL](https://arxiv.org/abs/1910.06591)：集中加速器推理与低开销通信；批量、样本效率和硬件吞吐需要共同选择。

## 模型与概率

保留宽 384、六层、六头、FFN 1536 的 Pre-LN Transformer，当前整组实现共 15,184,130 参数。上一组为 15,048,578；增加 query/key 评分头，删除旧全局浮点投影。公开实体及全局 token 完整参与各层自注意力；学习端每批一次前向和一次反向。

公开输入统一为 `haojie-public-tables-v3`：实体和全局行使用 60 个 int64 身份/字段、52 个 BF16 连续槽及两个整数存在/类型掩码，候选使用 64 个 int64。调试 JSON 使用十进制字符串保存 int64。进入投影时先做可逆 ZigZag 编码，完整 64 位分别对应可学习向量；常见负数无需重复展开符号位。原始行按值共享，参数路径、位置、绑定及逐层精确排除事实组成公开决策状态，替代 GRU 历史重放。Rust 不再生成旧浮点副本。

节点上下文经 GELU MLP 生成 query，候选与源/目标实体绑定后经另一 GELU MLP 生成 key。分数为 BF16 点积除以根号维数，再加 key 的可学习先验。同一根绑定的 key 在 CPU lane 缓存，排除动作不执行宽候选 MLP；返回的完整支持集保留原索引，排除项质量为零。学习按唯一绑定投影并反传完整主干，重复引用使用原生 CSR 归约。GELU 对完整 BF16 输入域查表，保持同一数值函数。

actor 与 learner 使用同一分段 BF16 策略定义。Rust 对实际 BF16 质量精确归一化并抽样，保存真实行为对数概率。learner 的重要性比采用相同规范概率；其前向值与可微策略梯度衔接。新策略质量为零时，V-trace 权重为零，零优势策略项严格置零，避免 0 与负无穷相乘。

## 宿主与所有权

生产运行由独立 C++ / LibTorch 宿主负责初始化、模型、推理、训练、优化器、调度和保存恢复。Rust 持久 actor 只持有规则与逐局状态，固定由所属 CPU lane 使用，规则对象及 Rc 不跨线程。模型仅接收公开白名单；正式状态、两个 RNG 和暗选内容留在规则侧。

CPU lane 在一次规则调用返回的有效视图上直接解码，持有规则、轨迹未决项和部分块，评分后立即推进。各环境在 lane 内公平轮转，控制线程接收完整块和控制完成事件。独立根服务接收缺根请求，集中使用两个有界 GPU 槽，将结果与对应的不可变头部快照直接交回所属 lane；CPU 行、候选和绑定 key 缓存均绑定该快照。单个原子阶段表示 CPU、排队根、在途根及空闲之间的所有权交接。发布只等待已提交 GPU 读取，已开始的 CPU 决策持旧快照完成。学习提交回执先记实际消费，再处理发布。

CUDA 图固定形状、地址及输入输出存储，在并行工作启动前统一捕获。每个槽的共享图池只在同一流顺序使用；临时激活不逃逸。根输出写入槽拥有的连续 BF16 缓冲，一次回送后复制为每个根拥有的 CPU 结果；槽立即可以复用，CPU 决策不持有设备结果。实际类型化字节集中上传，容量不足时执行同一完整普通计算。[PyTorch CUDA Graph 文档](https://docs.pytorch.org/docs/stable/notes/cuda#cuda-graphs)说明捕获及地址要求；原生图类的条件成员布局也要求匹配发行库的 CUDA 头版本。

CUDA Runtime/CRT 头包由构建入口从 NVIDIA 官方清单下载并校验；LibTorch 提供 NVRTC。运行不调用 nvcc、Python 或 Node。原始行投影、真实长度均值和搬运使用原生设备内核。

完整类型化行和候选在进程内共享，不反复复制相同参数事实。共享单元、根和节点按所有权存活期收费，最后一个引用释放时自动归还预算。原始输入、未完成轨迹、待学习块、学习在途块、CPU 队列、Rust 活动分配和两端根缓存一起记账。内存紧张时在真实后继处切出短块，完成块只转移已有数据归属。缩容将整局停放并释放规则树、根缓存；没有活动局的 lane 同时释放策略缓存及快照。扩容先恢复旧局。

## BF16 更新与持久化

模型、激活、梯度和五组补偿 AdamW 浮点状态保持 BF16。完整反向覆盖本批梯度，整包写入固定梯度存储；不先清零再逐参数累加。CUDA 以两遍相同逐元素算式执行更新：第一遍只验证全部结果和损失，第二遍在验证成功时复算并共同提交参数及五组状态，省去六组全参数提案表。每个显式中间结果仍按 BF16 舍入；标量倒数与 ATen 规则一致。CPU 保留通用数值路径。四个更新阶段逐位对照，以及 NaN/范数溢出的原子拒绝，均纳入功能检查。

归一化均值、逆标准差及注意力 LSE 跨前后向保存时也量化为 BF16；算子内部的 FP32 累加只作为计算暂存。CPU 注意力显式使用 BF16 矩阵、softmax 和输出。稠密和稀疏投影允许 BF16 归约顺序误差，实际行为概率始终按规范质量精确记录。

原始整数表集中上传并在设备展开为 BF16 零一矩阵，张量核心执行类型化投影。学习 batch 不超过 64 时使用 128/256/512/1024/2048 个根 token 的容量族，行、候选、绑定 key 与路径容量由 batch 单独决定；候选或路径较宽不会扩大 Transformer 的 token 表。各族共用稳定参数、梯度和五组优化器地址，捕获一次前向、规范概率、V-trace、损失、反向及条件更新。普通学习与重放共用同一梯度存储，普通回退后可以直接继续重放。查询和 key 使用独立累计长度，填充梯度归零；超容量执行同一完整普通学习器。捕获及热身禁用提交。全部提案与损失验证后才共同提交参数和状态，宿主只读一个回执。CPU actor 的 17 个头部张量整包传输，bootstrap 保留完整编码与价值分支。

检查点暂停 lane 的继续推进并排空已提交工作，在一致边界冻结模型、优化器、配置、正式状态、RNG、路径、排除 frontier、未决转换、部分轨迹和待学习块，后台原子写入。v3 共享表包含类型化全局行，恢复原样还原共享关系。停放统计在规则对象实际移除后更新；缩容请求在当前原子步骤完成后生效。窗口在退出排空前冻结，累计数与本轮速率分开；UTC 起点用于对齐 GPU 采样。

## 按整体结果选择

先调查再实施整组替换，功能与状态检查通过后测完整管线。正常运行用于 main 对照；固定真实工作集用于同工作量曲线，实际消费、模型规模、训练预算、积压、窗口及完整进程墙钟分别报告。原始结果和源码身份见[实测](MEASUREMENTS.md)。

填充 embedding-bag 图版本、新根串接策略加事件轮询、缓存命中与缺根统一设备批，均按整体负收益撤回。失败结果摘要和冻结源码保留，生产路径无兼容开关。已结束测试的检查点及重复实验产物按作者要求清理，保留范围见[实测记录](MEASUREMENTS.md)。

各次完整结果见[实测](MEASUREMENTS.md)。`cohort`、`ready-tables`、`root-service` 和最后的 `packed-handoff` 均保留原始数据与冻结源码。最后一组正常短窗正式命令吞吐约为 main 的 2.70 倍，实际消费 27,168；同一 4,096 转换工作集的 1→2 对数斜率为 0.390，扩展目标未达到。按作者要求，本组测量后停止后续优化与评测。
