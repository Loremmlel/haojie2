**这组 16 并发实测没有取得正式命令吞吐加速：新版窗口吞吐比 main 低 23.66%，按窗口产出除以完整进程墙钟的口径低 24.95%。** 新版执行了更密集的连续学习；实际消费和更新次数如表列出。main 的终局样本与新版的带 bootstrap 连续微步分别计量，二者的数量比不作为整体性能倍率。

main 的 256 个保留样本实际消费 512 次；窗口结束时另有 16 个在途局、54,852 个尚未进入终局池的已见决策样本。新版窗口末为 ready 0、partial 155、pending 8、学习在途 512；其累计产生满足 `18,075 = 17,408 + 155 + 512`。这 512 个在途学习微步在退出时完成，保存状态累计消费为 17,920，窗口产出仍固定使用 17,408。

main 退出取消 16 个未完成局；新版保存了 16 个在途局和轨迹进度。未完成局不补终局结果。计时是本轮单次完整运行的实测值，不取先前短跑的中位数，也不混入退出排空产出。

GPU 指标由独立 `nvidia-smi` 每 200 毫秒采样，覆盖完整进程生命周期及设备上原有图形应用；RSS 为每 200 毫秒观察的进程树峰值。完整墙钟由外部父进程从启动前计至进程退出，编译与安装在正式测量之前完成。

## 本轮观察

平均推理批量为 main **5.07**、新版 **14.56**，推理请求分别为 52,579 / 34,879。新版合批更集中，但本轮采样推进仍较慢，学习与内存开销更高。新版推理区间累计 31.30 秒、学习工作区间累计 20.53 秒；区间包含组表、同步及提交等待，整体成本读取完整墙钟。

本轮只测最终要求的 16 并发点，不据此填写并发扩展斜率或 GPU 饱和拐点。后续优化需要保留 Transformer 容量，分解当前推理与学习的实际开销，再用同一 16 并发入口复验。
