# 本地训练控制台

用于长期桌面训练的内存优先模式。完整记录、逐条审计、固定数据指纹续训仍见 [NATIVE.md](NATIVE.md)；两者不共享虚构的数据指纹，不改写旧记录。

## 启动

已有本仓库 Python 3.12 虚拟环境与正式 Rust 构建时，在仓库根目录执行一条命令：

```powershell
& training/.venv/Scripts/python.exe -m haojie_training.console
```

首次安装/更新一次 `training/.venv/Scripts/python.exe -m pip install -e ./training`，原生引擎更新一次 `npm run native:build`。安装阶段需网络；运行阶段不需 Node、tsx、前端开发服务器或 CDN。现有 CUDA PyTorch 安装保留；CPU 安装可先按 [安装说明](NATIVE.md)选择 CPU wheel。已安装包也提供 `haojie-console --engine <正式二进制路径>`。自动打开 `http://127.0.0.1:8765`，自动选择设备；首次开始创建现有默认网络，已有恢复点则加载最新完整点。没有自动开始长时间训练。

可用 `--device cpu/cuda`、`--no-browser`、`--port 8765`；`--import-weights <现有检查点>` 仅用于没有恢复点的新服务，检查规则/编码，复制权重而不修改导入原件。`--tiny` 是接线验收小模型，不代表正式棋力。教师 V8 缺失会显示未就绪，安装入口为 `pip install mini-racer==0.14.1`，不填假成绩。

## 使用与恢复

- 五页：概览、评测、资源、设置、日志。桌面概览一屏，顶部控制固定；长内容只有中间一个滚动区。关闭、刷新或切页不停止服务。一个进程持有一个会话，同一受管目录有操作系统排他锁，重复开始幂等。
- 采样、更新、评测分时使用 GPU；每轮采样结束后更新，下一轮使用新行为权重。暂停在短计算边界取消在途局及评测，丢弃未终局样本，不等待长局结束。学习器/AdamW/AMP 留在内存，暂停移回 CPU，继续不重建优化器。
- 默认每 600 秒且有新更新保存；可设置新增有效终局触发或手动保存，请求合并。暂停不强制补保存。最近两个完整恢复点包含模型、优化器、AMP、随机状态、更新与任务计数、配置及协议身份；不保存数据池。临时文件写后回读校验、原子替换成功后才轮换。
- 同进程继续使用内存最新状态。退出/重启只恢复最近完整磁盘点，RAM池为空。概览显示当前/已保存步数、保存时间和现在退出可能丢失的进度。崩溃后的准确丢失数量无法重建；不会声称精确重演历史。
- 错误显示原因并停算；释放在途资源后可重试。配额不足保留有效恢复点；模型非有限值则应重启恢复已保存状态。资源不足时可暂停后降低环境数、批量与样本池。

## 学习方法与对手

复核 [随机博弈调研](https://github.com/Loremmlel/haojie2/blob/0690c93fc1d8caeb5f533240ecdedb026942ad7f/docs/ai/research/STOCHASTIC-GAMES-2026-09-26.md) 后，本轮只实现一种收益驱动原型：`decomposed-mc-q-v1`。复用现有候选评分头，以真实终局收益回归实际生效分解选择的 `tanh(score)`，并用 `Q / temperature` 作为后续 Gumbel 排序分数；状态价值头同样用真实终局收益。不是策略梯度，不假设回溯/权威拒绝后的行为概率等于首次 softmax，不将被拒绝候选作为执行标签。

该方法是有限样本、非平稳对手下的分解 MC 动作价值实验，没有承诺收敛或棋力提升。单个终局会监督多个相关分解选择；超大样本过滤与有限保留改变可学习分布；可选不执行路径尚无独立价值监督。小型反事实收益测试仅证明正负终局信号能改变实际候选排序，不证明自然对局策略改善。因此界面持续标注：**自对弈数据与训练接口已接通，策略改进实验尚未完成**。`sampled-action-imitation` 仍是可在初始化前选择的接线基线，不称强化学习。

默认当前对当前与当前对历史各约一半。历史池默认 4 份（可 4—8），初始一份，之后每 200 次有效参数更新稀疏纳入仅权重快照。每轮只加载最多一个历史模型加当前模型；一局双方身份固定，按实际行动者路由，历史方动作不进入当前学习池。当前对当前双方都按自己的公开视角学习。学习器不因评测较差回滚。恢复点、历史对手、最佳评测权重是三个身份，全部计入配额。

## 内存和磁盘边界

普通轨迹、特征、样本不先写文件，也不溢写全量RAM池。原生出口复用 `records::examples` 的编码与已执行路径校验，只在权威接受命令后发送；终局前没有价值标签。默认每局对合格分解样本做均匀蓄水池抽样，最多64条、每条保守512KiB，最多约32MiB/局；页面报告保留数、总数和超大拒收数，不只保留最后几步。传输帧保护2MiB，超限局按错误取消，不裁剪实体假装完整输入。

可训练池按保守张量字节加对象余量计账，默认至多4GiB并取可用RAM四分之一。随机抽样、每条最多复用2次，字节压力FIFO淘汰旧样本。协议帧零拷贝传入；未全面共享不同分解阶段的实体张量，保守额度与均匀抽样限制其代价。当前批次、学习器、AdamW、最多一个历史网络、原生工作进程及V8仍占额外内存，页面展示进程树RSS、在途样本、GPU显存；可用RAM低于256MiB停算。并行环境最高16，并非总RAM只占4GiB。

默认统一受管根为 `~/.haojie-training`，所有恢复点、历史池、最佳模型、指标和原子临时文件共享 **20,000,000,000 字节**。`--root` 只用于迁移整个根/验收，不能给每个任务开一个20GB目录后声称全局合规。代码、已安装运行库和正式引擎不属于训练产物。无诊断全量轨迹、无磁盘训练样本池、无逐命令fsync。当前保留两个恢复点、4—8历史权重、一个合格最佳权重、一个最多2MB指标JSON与1字节锁；日志100条、曲线256点上限并降采样，仅最近两轮保留逐局小摘要。没有指标数据库/WAL。

所有写入经统一Store，先预留完整临时文件空间并计入其他在途写入，不能超限后再删除。保存先在RAM序列化以取得准确字节数；序列化及回读有短时RAM成本。保护旧恢复点、先回收已可淘汰自有文件，不够则拒写并停算。指标至多每60秒聚合或每轮评测结束写一份，目录每60秒核对；UI轮询只读内存计账，不扫描目录、不触发落盘。显示已用/预留/分项/60秒平均写速/本次进程累计写量。

启动只读盘点仓库 `artifacts`（排除原生构建目录）；其他旧数据用 `--legacy <目录>` 补充报告。**未纳管旧产物另外列占用，不被删除，也不声称整台机器的训练文件小于20GB。** 用户可 `--adopt <旧目录>` 显式计入总额，原件受保护、不自动删；路径清单持久化。纳管目录不应再被其他工具并发写入，外部写入只有低频核对能发现，不能由本服务阻止。禁止受管目录的符号链接/联接，拒绝将非空用户目录直接当自有根。

## 外部棋力评测

随包静态JS由真实 `TrainingTeacher`、`difficulty.ts`、planning/search/cache依赖构建。运行使用 mini-racer 0.14.1 的 Python ctypes + 嵌入式V8库，不启动隐藏Node，也无需浏览器；构建阶段才用esbuild。每局独立教师与256MiB V8堆限额，保留教师固定工作预算语义，单次调用2秒保护；原生引擎裁决双方公开观察及命令。对手指纹来自全部打包源码/构建清单；CI `train:teacher:check` 防过期。

默认每新增200有效训练终局且有新更新触发，独立于保存间隔；三档各经典/神龛一对交换先后手，共12局，独立高位种子。默认整轮600秒，剩余局记未完成。最多一个待评测请求；手动立即评测、取消本轮、训练暂停均支持。评测只使用冻结内存权重，不保存逐步状态，不进入训练池。配置/对手指纹变化产生新系列；曲线仅连接同系列。

显示胜负、规则平局、未完成/错误、完成率、有效样本、胜率与平局半分得分率。无有效样本显示未评测，12局只是趋势。最佳模型规则：每档至少20有效局且整轮完成，同系列平均得分率超过已存最佳；新系列首次满足条件可成为该系列基线。只保存权重和评测摘要，不因此回滚学习器，不是统计显著晋级证明。训练与评测共用单控制器分时GPU。

本轮复用 `TrainingTeacher.next` 的 decisionOwner 入口；它不额外发起模型采样器支持的非决策方可选巨大化窗口。该差异在系列身份中由教师适配源码指纹固定，不能把结果当作所有UI真人/AI调度路径完全等价。

## 验收

廉价测试入口：`python -m unittest discover -s training/tests -p 'test_*.py'`，显式设 `HAOJIE_NATIVE`；缺引擎失败、不静默跳过。覆盖缩小磁盘配额、原子失败保护、1000次指标写入、10000条内存事件、收益改变候选排序、真实三档教师与引擎、真实小模型更新/暂停/继续/恢复和假时钟保存。

真实浏览器：`node tests/browser/console/run.mjs`（按环境指定 `BROWSER_PATH`）。使用已登记晚盘夹具缩短训练，验证非空样本与真实参数更新、多页面同会话、固定布局、暂停、恢复回退、评测隔离、取消与磁盘压力。夹具结果不进入正式棋力曲线；短预算的12局适配试验只报告未完成。验收产生的独立临时产物在 `artifacts/console-browser-*`，下次启动作为旧文件单列，不悄悄删除。
