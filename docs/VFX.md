# 棋局特效：视觉与播放契约

基线：`0bb962fdace51380fac0b11aa01603b848125323`。本轮按已批准方案升级原生 React / SVG / CSS 表现，局部使用原生 Web Animations API；没有新增依赖、素材服务、运行时请求或存档版本。

## 视觉方向

纸色、墨线、青绿/朱红阵营，少量金色、冰蓝与紫色功能色。辨识度来自形状、流动方向和节奏，不来自满屏光晕。近身用短促斩痕和探身，射手用箭头与箭身，重炮有收束与后坐，投石机有石块与挂印，钩子分投射与实际牵引。普通远距攻击有短光梭，不把远距离伪装成贴脸挥刀。

治疗与吸血使用有方向的流光；只有实际回复生命才有吸血回流。爆弹标出真实2×2格，风暴沿整行/列分段点燃，十字浩劫和震地按规则提供的格子绘制。护盾、结晶、灼烧、沉默、装备、蓄力、入场和死亡共享少量有区别的图形家族。不是每个图鉴条目各做一套动画：未专门设计的普通攻击/辅助能力仍有安全通用表现。

策反和处决的 **apply** 仅附着待触发印记，**trigger** 才表现真正转化/消灭。反制/免疫显示保护响应，不生成假的伤害/成功施法区域。名刀保护致命伤仍可能有真实扣血，保护与伤害反馈可以同时存在。持续印记、危险区、冰面、虹吸连接的存续一律来自当前规则状态。

## 数据与职责

```text
applyCommand 完成规则 → 原有 GameEvent + 可选事实快照
  → planEffects（纯函数）→ useEffectPlayback（短时批次）
  → Effects / Shapes（SVG）+ PieceFace / PiecePosition（原生局部动画）
```

`engine/event-facts.ts` 只描述动作语义，不保存色彩、播放时长或粒子参数。它通过同步作用域给原有事件补充 action、stage、ability、actor、subject、area、causeId、parentId。来源/目标快照只含 ID、归属、种类、坐标、尺寸，不引用可变 Unit，不复制完整血量/装备对象。范围只附到需要它的动作事件，避免每条伤害重复携带整行格子。

不为视觉增加 serial-bearing 规则事件、不消耗正式随机数、不修改规则值；同一动作以已有事件 ID 分组。嵌套反击有独立 causeId 和 parentId；异常退出立即恢复上下文。引擎入口依旧不依赖 React、DOM、时钟或存储。较旧事件缺少新字段时，表现层安全降级；载入/重做并不重播存档里的历史事件。

`plan.ts` 集中管理视觉家族和时序，不复制伤害、技能射程和概率。攻击使用实际路径，并且只在本体占位内部连接视觉中心；不会把一条绕障弹道替换成穿障直线。大体型以尺寸快照确定中心；死亡和死亡反击仍能使用离场快照。

出手、飞行、命中、数字共用时刻。叠放/连续命中的数字分配显示槽位；同一次作用于同一目标的同类数值可合并，真实引擎日志不合并。范围攻击并行反馈，不把每个格子排成漫长队列。反击在父攻击命中后表现，极长连锁压缩延迟，不阻塞真实规则或人类反应选择。

`PiecePosition` 在真实新坐标上用临时 transform 沿记录路线移动，牵引在钩子到达旧位置后移动；不再让 left/top 布局动画直接穿过路径障碍。`PieceFace` 只做局部探身、后坐、受击/入场。两者取消时都释放原生动画；不按帧更新整张 React 棋盘。

## 生命周期与性能上限

最多同时保留 **4批、96条可见 cue**。同批先保数字/离场反馈，极端积压淘汰最旧批次；这是表现降级，不丢弃规则结算、持续状态或战报。每批按自己的完成时间回收，新指令不直接替换旧动画。播放序号独立于游戏 serial；悔棋、载入、新局、卸载清理效果和相关动画。

SVG `animateMotion` 在插入时显式以相对当前时刻启动，不能假设父SVG也刚刚创建。每个飞行动画随节点销毁而取消。播放不改变 AI 计算预算、缓存、落子节奏和规则PRNG。

减少动态效果时不创建飞行轨迹动画，取消棋子运动，保留短暂的静态范围、目标符号和数字。不开全屏闪白、震屏，不用大量动态 blur/drop-shadow。无持续的 React 帧循环。当前上限只是防积压护栏，不宣称任意手机上固定60帧。

## 开发预览与验收

`npm run preview:vfx` 输出 `artifacts/vfx-preview.html`。打开后选择场景、播放或连续点击，复位即取消；22个场景全部通过真实引擎命令生成。预览代码不进入发行入口，也不生成额外生产分包。覆盖近战、射手、赤焰重炮、挂标、牵引、治疗、爆弹、策反/处决施加与触发、免疫、风暴及再临、十字浩劫、寒冰、吸血、蓄力、冲撞、反制、入场和虹吸结算。

新增6项稳定行为契约，现共155项：类型/路径、快照与身份变化、范围/成功与失败、因果命中/反击、纯函数/旧存档、批次并存与上限。浏览器验收按可见行为检查真实飞行、代表动作、快速连点、减少动态效果、390px布局、立即扣血、两次攻击并存、悔棋/重做/载入/到期清理与零外部请求，不用像素快照锁死每条装饰线。

本地已核验155项行为测试；22个场景与冻结基线逐项比较所有非events状态（含rng、serial、日志、单位、卡牌和反应队列），并确认事件数量与ID一致。旧214条及上一轮115条CLI命令回放匹配。新增事实快照只改变事件附带信息。

沙箱禁止file://导航，本地浏览器检查使用明确的 `HAOJIE_RENDER_ONLY=1` 内存渲染；不把它当成离线文件打开/本地存储验收。正式PR CI需运行格式、类型、行为、deploy:check、离线file://、HTTP/嵌入、AI及新增特效浏览器验收，并回放两份历史CLI记录。全部通过后再合并，源码与根index.html一同发布。

## 边界

本轮不重写音频节奏，不延迟真实血量或胜负判定，不变更规则/AI数值，不引入图片帧动画、Canvas/PixiJS、GSAP或通用时间线DSL。特殊单位仍可在这个结构上扩展视觉身份；复杂连锁的可读性和低端真机性能仍需要真实游玩反馈，不能由少量截图证明。

## 审查补充 · 2026-09-11

牵引的 `impactTo` 是钩子接触的旧位置，`to` 仍是实际移动终点；旧位置先有接钩效果，位移动画结束后新位置才显示收尾标记。移动与收尾共用时长，批次寿命覆盖整个动作。规划器原本已经限制单批数量，现在 `appendBatch` 也独立使用同一优先裁剪，直接传入超大批次仍保留最多96条，并优先保数字。两处补充并入原有行为契约与浏览器检查，测试总数仍为155。

最终根HTML为602350字节，较基线增加25971字节，约4.5%。此数字不含独立开发预览；原有依赖锁文件未变。
