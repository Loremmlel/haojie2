# 棋局特效升级

基线：0bb962fdace51380fac0b11aa01603b848125323。范围：原生 React / SVG / CSS 表现层，不改规则、AI、存档版本，不增加运行时依赖。

## 视觉契约

纸色、墨线、青绿/朱红阵营、少量金色。用动作形状、方向与节奏区分斩击、箭矢、炮击、投石挂标、牵引、治疗、范围与延迟效果。范围服从引擎实际格子；相邻斩击与远程表现不同。策反/处决施加印记不等于触发成功，免疫/反制不能播放成功效果。血量与规则立即结算，动画永不驱动结算。

## 工程计划

1. 扩充现有事件的可选事实快照和因果关系，不增加视觉专用规则事件、不改变serial或PRNG消耗。
2. 纯表现映射生成短时播放计划：同一动作统一出手/命中/数字，嵌套反击与范围伤害正确分组。
3. 有上限的播放批次并存与独立回收，悔棋/新局/载入/卸载清理。持续区域继续由状态驱动。
4. 原生SVG特效家族、棋子局部动作、减少动态效果降级；开发预览独立产物，不进入发行HTML。
5. 少量稳定行为契约覆盖语义、路径、范围、生命周期；真实离线浏览器检查连续动作、取消、移动端、减少动态效果与零网络请求。
6. 同步文档与根index.html；完整CI通过后合并发布。保留真实测量与尚未验证事项，不声称固定帧率。

实施与验收结果在完成后补充。
