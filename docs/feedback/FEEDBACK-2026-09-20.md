# 问题反馈3 · 2026-09-20

来源：作者本轮“继续更新浩劫2 / 问题反馈3”。本文件优先于历史更新中与本轮冲突的规则；未指定处沿用现有规则，不重设计其他模式。

## 实施范围

- **超级BW**：每生一次免费巨大化，自己攻击/当前血量−10，目标当前及最大血量+5。允许敌方；先选择目标，再在四种包含原格的2×2落位中选择，不与棋子/地标/基地重合。部署、召唤、对手回合可用；不能打断已开始的原子反应。人机模式仅人类自己的技能可插入AI回合，选点期间废弃旧AI计划，提交/取消后继续。
- **基地/冰冻**：友方攻击可穿自己基地。冻结保留阵营及光环、名刀、改判、法术反制等常驻被动，但封锁操作。炎魔自动攻击在冻结时停止，沉默后则可进行普通攻击。
- **治疗/虹吸**：六类原生治疗角色与继承治疗者可自奶。U14生命40，虹吸消耗一个操作，每实际回合一次、最多3条，支持自己/棋子/双方基地端点，超射程断开，号令不刷新使用次数。
- **举旗**：只能新部署到(4,7)/(5,7)/(6,7)，中间横向三格。
- **伤害来源**：所有伤害法术及延迟风暴来源是真实的己方基地；反伤/反击可作用基地，法术击杀记己方人头。法术与法师伤害AOE排除友方棋子/地标/基地。
- **AOE**：每个覆盖格独立伤害，2×2爆弹全覆盖80、两格40、一格20；十字、风暴、炎魔主格/四向溅射同理。逐包处理免疫/反伤/受伤成长，不能重复产人头。普通穿透是每个目标一次，不是每格一次。
- **移动**：2×2每步整体平移一小格，逐步校验全部四格，共用本次移动预算/蓄力/操作。小BW与SZF可穿过装备、叠放、地标覆盖物及基地；仅碰撞敌方造成30伤害。最终回到空位，过渡占位不能插入其他操作；SZF保留免费弹出，小BW必须留足步数离开。正常地标部署不属于未结束冲撞。
- **武器**：保持一槽替换，撤销旧武器数值，不叠加上限。炎魔之心保留非法师、+5血、冰免、冲锋部署当回合禁装及储存10回合。
- **炎魔之心攻击**：保留原普通攻击/治疗，额外支持长度≤射程的可转弯四向逐格路径；路径上敌方栈顶/地标各受一次原攻击及灼烧，不自动延长。命中多个目标仍只花一次攻击，各自保留原暴击/吸血/入射方向/击退等效果。敌方基地只能是终点，路径不能循环或跳格。
- **界面**：棋子能力与继承技能常显，状态可折叠；新增自奶、2×2方向移动、穿透路径撤回/确认。全部复用现有引擎合法性和纸面风格。

## 兼容与实施选择

存档仍为v2，保留已有存储键、随机语义、撤销/重做。旧举旗在(7,8)/(7,9)/(7,10)的合法历史位置只在载入时保留，不自动搬迁旧棋子；新部署只有新三格。旧部署单位的历史快照不批量改写基础血量；新召唤/复活灵魂法师使用40血模板。

一槽替换是既有装备约定，本轮明确“一棋一武器”后继续沿用，不改成禁止更换。敌方金身/免疫塔等仍可拦截巨大化，付出技能成本和一生次数；非法占位则整条命令拒绝，不扣成本。大肉比震地并非法师AOE，保留其原敌我范围，但采用逐覆盖格结算。

AI不枚举所有自由手绘路径，以目标+最多四个入射方向构造有限候选；使用同一穿透合法性并保留真实路径，避免指数级搜索。棋力未在本轮宣称提升，八回合烟测只证明该样本合法推进。
