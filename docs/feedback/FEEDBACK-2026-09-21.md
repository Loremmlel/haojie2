## 部署行：保留回合开始快照，不改成实时人数

基线`refreshDeployment`已实现人数差大于等于2，且只在回合开始刷新。蓝方1默认01–08行、红方2默认06–13行；双方镜像用蓝方09、红方05测试。

| 回合开始人数（己方:对方） | 额外行可部署 |
| ------------------------- | ------------ |
| 1:1                       | 否           |
| 2:0                       | 是           |
| 2:1                       | 否           |
| 3:1                       | 是           |

每枚棋子在其触及的每行各计一次：2×2同一行只算1枚，叠放的独立棋子各算1枚。权限不是永久解锁，也不因回合中移动/死亡/策反立即刷新。

因此同一回合中可能看见1:1仍可部署（开局时2:0），也可能看见2:0不能部署（本回合刚形成优势）；下一己方回合重新判断。这可以解释反馈现象，但没有原局面就不能断言它是用户遇到问题的实际原因。仍需满足完整占位、基地、独行侠禁区等其他限制；U27/友方生效地标保留已有特例。

新增测试覆盖完整回合交接、本地和在线高亮及权威提交、人数快照跨移动/存档/公开投影，以及2×2和叠放计数。本次未改写正确的部署算法，也未在读取存档时按当前棋盘重算权限。
