# 增量存档实施计划

目标：新存档保存初始完整局面、当前路线的全部命令和当前完整局面，减少重复快照，同时支持续玩、复盘和训练预处理。

1. 保留运行时最近60步快照，增加带规则版本的命令记录。悔棋移动记录游标，另走截断后续命令；导出只包含游标之前的路线。
2. 新增统一序列化入口，网页导出、本机自动保存和CLI使用同一格式；存储键不变。导入重放校验当前局面并重建悔棋缓存，拒绝规则版本不符或记录损坏。
3. 旧v2存档继续校验和迁移，原快照仍可在当前会话悔棋；增量记录只能从已知局面开始，明确标记为局部记录。空间不足时保存当前局面的降级仍明确提示。
4. 提供存档到训练JSONL的转换：按实际操作者提取公开Observation，保留动作与真实终局标签，不泄露随机状态和暗选信息，不伪造教师搜索统计。
5. 覆盖超过60步、悔棋另走、长AI回合、人机锚点、随机/反应/神龛、旧档和损坏记录；更新浏览器契约与文档，执行格式、类型、行为、离线浏览器、发布一致性及当前CLI回放检查。

范围：不保存撤销分支，不修改游戏规则，不改写历史回放，不添加依赖。导入需要一次顺序重放，暂不加入检查点或压缩层。
