# 规则契约 · 解释版1.0

这是对原始需求的可执行解释，不代表存在歧义的条款已经获得规则作者确认。棋子名称、基础数值、能力说明与游戏内图鉴共用`src/engine/catalog.ts`。交互不会自动简化成“所有棋子都只能普通攻击”。

## 核心规则

棋盘9列13行，共117格；坐标从1开始，(5,1)和(5,13)是双方300生命的基地。先手为苍穹方，后手为赤焰方。每个己方回合开始独立随机召唤两次，死亡遗赠等可增加召唤次数。召唤池按26个编号等概率、有放回抽取，抽中3后再判定是否变为3′。

随从当回合必须部署，新部署随从通常下个己方回合才能行动。每一点行动可选一次移动、攻击或技能；冲锋、定炮、大肉比、独行侠等遵循图鉴中的特殊规则。法术不消耗随从行动，可以储存后施放。

苍穹默认部署行1–8，赤焰默认部署行6–13。每个己方回合开始，额外行按当时的单位数量计算：己方至少多于敌方2个，才可在该行部署。占2×2的随从在接触的每行各计一个；基地不计。中途改变阵型不立即刷新部署权限，下次己方回合重新判定。

## 需要作者确认的主要解释

| 条款                     | 当前实现                                                                |
| ------------------------ | ----------------------------------------------------------------------- |
| 原始距离式`abs(c+d-a-b)` | 曼哈顿距离`abs(c-a)+abs(d-b)`；原式会使部分不同格子距离为0              |
| 3′的乱码攻击公式         | `max(0,40-5n)`，n包含自身、双方与衍生随从，大体型只计一次               |
| “储存N回合”              | 按己方回合，包含抽到的回合；第N个己方回合仍可使用，下次己方回合开始过期 |
| 每回合移动格数           | 每次移动行动的距离上限，不是整回合共享的移动预算                        |
| 定炮的1/3行动            | 每个未开炮的己方回合结束自动蓄力；部署回合也计，2格可开炮、5格射程+1    |
| 大肉比的半格移动         | 先消耗一次行动蓄步，后续移动行动整体四向移动1格并清空蓄步               |
| 名刀的保护次数           | 每个被保护随从一生一次，含名刀自身；名刀0行动，因此不能主动移动         |
| 钩子落点                 | 可重新放到钩子射程内的合法位置，不要求沿移动路径拖行                    |
| 献祭炮的“第一敌方”       | 选定列、进攻方向、射程内的第一个可命中敌方                              |
| 神行千里蓄力             | 两个不同己方回合各花一次行动，之后的己方回合可发动突袭；扣血后必须存活  |
| 独行侠“两回合才能行动”   | 部署后的第二个己方回合首次行动，之后隔回合行动；周围一圈为八邻域        |
| 厚脸皮的并列路径         | 最短合法攻击路径并列时，只要其中有正面进入路径，就按正面结算            |
| 策反顺序                 | 先伤害；受害随从存活才换阵营，致死伤害不复活，新友方进入部署疲劳        |

## 伤害与特殊结算

移动不能穿过任何单位或基地。攻击可以越过友方，但不能穿过非目标敌方；存在一条不超过射程的合法四向路径即可攻击。大体型单位以占据格集合参与判定。

普通伤害和直接消灭是不同的操作。金身只阻止伤害，名刀只阻止一次致命伤害，均不阻止献祭和处决。献祭炮降低生命上限不是攻击伤害。基地不能被移动、治疗、献祭、策反、处决或受到名刀保护，但能受到爆弹友伤和投石机标记。

一次爆弹先锁定区域内目标列表，大体型只登记一次，随后按状态中的单位顺序结算伤害和死亡被动，再结算基地。连锁反击立即结算；需要玩家选择的临终攻击、伤害转化排入队列。在处理完当前命令后，由效果所属玩家按队列顺序选目标或放弃。原来的主动回合不会因此切换。

攻击成长在击杀时先结算，再处理被击杀者的死亡效果。比如杀手第一次击杀超级跑得快，会先获得10生命上限并治疗10，再承受20反击伤害。

投石机对随从和基地采用同一标记规则：满血立即触发；否则等同阵营的非投石机再次命中，或到施加方下回合开始过期。标记不因单纯“被攻击”以外的范围法术而触发。

## 结束、悔棋与无处部署

基地降至0，在当前命令全部伤害结算后判负；若双方基地同时为0则平局。胜负确定后清空等待反应，不再接收新战斗命令，但可以悔棋。

仍有合法格的随从必须部署后才能结束回合；完全没有合法位置的随从会在结束时被明确弃置并写入战报，避免棋盘拥塞造成无法继续。

悔棋支持最近60步，包含跨回合撤销；随机数、召唤结果、状态计时、死亡选择与战报一起恢复。重复同一操作不重新掷骰。界面同时提供重做、JSON存档导出/导入及本机自动恢复。
