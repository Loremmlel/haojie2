# 浩劫2.0规则契约

依据`source/浩劫.docx`，原文保留在`source/浩劫-原文.md`。本页明确区分作者确认与实现尚需采用的边界解释，不能把后者当作已经得到作者许可的规则更改。

## 已确认的基础规则

9列13行、117格；坐标从1开始。苍穹基地(5,1)、赤焰基地(5,13)，各300血。普通库26个编号，通常每个己方回合召唤两次，等概率有放回；普通3额外判定名刀/3′。3′的攻击为`max(0,40-5n)`，射程n，n在自身3×3内实时计算，含自身、双方和衍生随从，每个大体型算一个。

随从必须当前回合部署，通常下一己方回合才可行动；冲锋例外。默认部署行1–8 / 6–13。额外行在己方回合开始按快照判断：己方随从至少比敌方多2才可部署；2×2随从在接触到的每一行各计一个。无位置随从可在结束时明确弃置，有位置则必须先部署。

第四属性是**选择攻击后的攻击次数**，不是任意行动点。每个普通随从一回合选择移动、攻击、技能、蓄力一种模式；进入攻击模式可继续攻击至攻击次数用完，也可放弃余下攻击，但不能改成移动或技能。操作次数和攻击次数分别记录。矿工第二操作、靴子攻击操作、免费能力和冲锋号令另行处理。

蓄力是主动的一种完整操作，层数不因普通移动自行减少。分数行为只能使用**回合开始已经持有**的层数：½移动需1层，定炮攻击需2层，神行千里技能需2层。名刀0攻击次数不妨碍蓄力/移动。独行侠部署后的第二个己方回合首次行动，此后隔回合行动。

攻击与普通移动按四向距离。移动不能穿过单位或基地；攻击可穿过友方但不能穿过敌方，只要射程内有合法绕行路径即可命中。SZF/小BW与穿透武器有明确例外。2×2随从以实际占据格参与判断。

储存期限按己方回合，包含抽到回合，第N个己方回合还可用，下一个己方回合开始过期。法术和武器采用相同算法。

基地不能移动、治疗、献祭、策反、处决或获得名刀保护；爆弹能误伤己方基地。**灵魂法师明确点名双方基地为目标，作为新增特例允许虹吸对基地加/减生命**，治疗最高300。普通治疗攻击不因此获得治疗基地能力。

投石机满血标记立即触发5伤害；不满血标记要等另一同阵营非投石机的攻击命中才触发。未触发标记至施加方下回合开始消失，基地也如此。不是每次打基地都扣5。

名刀每个被保护随从一生一次，含名刀自己。金身免伤并免一切敌方技能、法术，包含18处决和22策反；自身/己方非伤害献祭不被拦截。策反先结算伤害，存活再换边，当前回合疲劳、下一己方回合可行动，独行侠也不额外再休一回合。

## 终极召唤与人头

每击杀敌方随从，伤害所属方获得一人头；击杀者有击杀成长时同样结算。法术和持续效果保留来源玩家，不能因为没有活着的施法随从而丢失人头归属。自己的献祭/到期消失不记敌方击杀。

回合开始先选择普通或终极召唤。终极每次支付2人头，替换一次未揭示的普通召唤；不额外增加抽取次数，不能看到结果后补付。终极库28个编号有放回等概率，U12独立1/10成功。改判保留原抽取池，不重复收费；未部署的克隆全批作为一次召唤被整体改判。

普通20死亡按文档的新判定：1/2不给人头，否则反伤来源30；没有随从来源不虚构反击目标。克隆同批8枚最后一枚死亡才提供一人头并结算死亡被动。未部署的同批牌也计入该批存活状态；克隆不能献祭。

## 持续状态、武器和独立时钟

武器不消耗随从操作，装备者死亡后不返还武器。寒冰法杖限定文档列出的法师：普通19、终极6/13/14/19/20；不会因为名称里有“小法师”就把U3自动加入名单。

冰冻期间不能行动，攻击目标与阻挡中立化，双方可攻击且都不能穿透；保留原所有者，供解除后的归属、持续时钟、死亡和人头归因使用。眩晕只禁止操作，不改阵营。沉默永久移除原有描述/技能，被沉默的基础五项数值、已经获得的永久属性和装备仍存在。

冲锋号令不推进整个棋盘、不刷新其他棋子、不产生额外全局召唤。它只把目标的逻辑时钟推进一个己方回合：刷新操作、连击和首击状态，推进部署疲劳、预定18/22、已存蓄力和自身延迟冰标。所有权回合、法术手牌到期、全局火线仍使用全局时钟。**实际部署时刻独立记录，不能用号令绕过冲锋随从部署当回合的炎魔之心装备禁令。**

## 尚未明细的边界：本次明确采用的解释

以下是使游戏可执行的实施约定，不冒充文档明示：

| 未详细说明的边界          | 当前处理                                                                                                                                                                            |
| ------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 武器槽位和替换            | 一槽，再装备替换旧武器，不返还；撤销旧装备数值，再加新装备。弑君只加上限不直接治疗，炎魔之心加当前及最大生命5。                                                                     |
| 冰冻/灼烧时长与“每回合末” | 时长以受影响单位的己方回合计，冰冻2、灼烧6；伤害在双方每次回合结束结算。重复同类刷新，不叠加同类伤害；塔冰冻每次末合计10。                                                          |
| 中立归属与人头            | 原所有者保留；己方击杀原属于自己的冰冻中立者不获得敌方人头；冰冻者不算任何一方行控制。                                                                                              |
| 被冻结时的被动            | 光环、反制和主动/免费操作暂停；死亡被动仍可发生，除非已沉默。                                                                                                                       |
| 免疫塔“法术”范围          | 保护己方免受敌方施法或技能，不自动吞掉己方增益。每目标/每次效果成功保护消耗15上限；归零离场，不设独立的一生一次额度。                                                               |
| 末日守卫两个概率          | 1/5为100伤害，1/3为双倍，剩余7/15普通，互斥而非两个同时触发。                                                                                                                       |
| 精英杀手成长              | 暴击率上限100%，吸血率可超过100%；第五次击杀加一次射程。吸血按该次命中前的比例乘实际扣血，允许小数生命。                                                                            |
| 巨大化                    | 自己攻击和当前生命各−10，目标当前/最大生命+5；2×2扩展以原格为左上角，空间不足则拒绝整条命令。单独克隆可扩大，占位冲突的叠放不能强行扩大。代价支付后施法者需存活。                   |
| 改判与多个法师            | 每个活着的改判法师每回合一次。自我改判限定前5个己方回合且一次，不无限自我连锁。已有克隆落地不能改判剩余半批。                                                                       |
| SZF/小BW步数              | 一层移动蓄力换一个含5次四向单格移动的操作；SZF撞击后的弹出不花步数，选空地才暂停弹出。小BW不能把操作终点留在敌方格；处于重叠过渡时先完成移动，不能穿插施法。小BW不撞基地，SZF可撞。 |
| 多目标结算                | 捕获目标列表后依序结算；普通AOE技能对敌方克隆只取栈顶，法术取全栈。炎魔之王按专属描述取同格全栈。每个大体型每个区域伤害只计算一次。                                                 |
| 十字/溅射友伤             | 没有“仅敌方”的区域描述按双方均受影响；炎魔之王主目标为敌方，外围一圈溅射可伤友方。                                                                                                  |
| 心灵之火                  | 持续动态等于当前生命，不冻结施法瞬间的生命值；该最终覆盖值取代原攻击和固定强化。                                                                                                    |
| 复活窗口                  | 当前全局回合之前4个玩家回合以内且不是当前回合的阵亡记录；不重掷3/U12变体，不恢复装备/buff/巨大化。每记录只使用一次，0上限施法者离场。                                               |
| 超级钩子多次击杀          | 下一己方回合获得可替代攻击的牵引资格，不积累多个免费牵引。正前方按朝敌方基地的纵向相邻格。                                                                                          |
| 寒冰塔次数                | 选标记占用一次技能操作，不额外免费攻击；下回合触发不再花操作。                                                                                                                      |
| 厚脸皮之王反击            | 仍需合法射程和路径；同一伤害链中同一有向攻击对只反击一次，防止双方无限递归。                                                                                                        |
| 同血最高目标              | 炎魔之王按行、列、生成ID固定顺序选一个主格，保证种子重放一致。                                                                                                                      |
| 炎魔之心穿透              | 沿选择的四向直线直到射程末，命中每个敌方栈顶并灼烧，可直接选择被前排挡住的直线敌方；每个被命中者独立判定原棋子的暴击。普通基地攻击规则仍可用。                                      |
| 法术先被反制              | 先验证目标和代价合法，再依对手反制法师顺序判定；成功反制消耗法术但不发动其主效果。                                                                                                  |

## 结束、历史与存档

每条命令纯函数执行，非法操作不会部分扣血、扣人头或消耗随机数。UI目标预览在克隆状态上执行相同验证。基地归零在该命令全部效果结算后判负；双方同时归零平局，之后可悔棋。

死亡攻击、伤害转化、小屋召唤、SZF弹出进入显式反应队列。队列阻止普通命令；回合结束引发反应时，待所属玩家处理完才切换回合，不在UI中偷偷触发异步伤害。

悔棋/重做恢复最多60步快照，新操作清空重做分支。包含RNG、人头、手牌期限、武器、叠放批次、死亡记录、额外个人回合和未完成连续操作。存档有版本与结构验证，v1不静默升级成v2。

### 2.0存档兼容

工程更新保留`haojie-session-v2`格式及`haojie.session.v2`存储键。读取旧2.0存档时，仅给缺少期限的冲锋号令补上`drawnAt + 8`，已经到期者移除；同样处理悔棋与重做快照，避免撤销后恢复无限号令。其他单位、RNG和历史保持。1.x存档仍明确拒绝。
