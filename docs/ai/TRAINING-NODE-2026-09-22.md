# Node训练环境性能评估 · 2026-09-22

结论：继续使用Node作为第一版训练规则环境。常驻环境移除逐命令Session历史与存档序列化后，已有足够吞吐开展教师热启动、接入网络及小规模MCTS实验。当前教师对弈远慢于规则落子，不能把更换引擎语言当作完整训练速度问题的答案。

这不是对几十万局训练工期、浏览器模型延迟或对作者80%胜率的保证。模型结构与训练路线见[训练设计](TRAINING.md)。

## 测量方法

- 本机：Intel Core Ultra 5 225H，14个逻辑CPU，约31.5GiB内存，Windows，Node v22.23.1。
- 固定语料：`docs/playtests/cli-counter-freeze-20260921.jsonl`中的79条正式命令；测量前逐条验证原始前后指纹，不修改历史回放。
- 同一语料分别走直接引擎、常驻训练环境、带历史的Session与JSON编码、训练协议与JSON编码。后一项包含默认返回的公开Observation，未测OS管道通信。
- 微基准每项500次，动作描述查询50次；完整回放每轮30遍。预热后测3轮取中位数。4进程另做一次预热后聚合测量，不含启动时间。
- 教师测试从正式新局开始，经典和神龛各1局，种子20260922，easy、每次新搜索固定40节点目标，最多1200条命令、相对60个ply。缓存可零模拟，完整概率边界等可能超过目标；不是每条命令恰好40次模拟。
- 教师测试不输出样本文件，包含观察、决策、真实规则落子和命令边界取消检查。分别记录观察、教师调用和规则落子的耗时；计时不影响选招或预算。

原始数据已归档为[node-20260922.json](benchmarks/node-20260922.json)，完成时间2026-09-22 02:34:58 UTC。基线提交为`28133f83a0a3468972772458bc9c89a4ca64220c`，另含本轮未提交的训练接口；相关源码SHA256为`6fc6bba37ea859c57e05ec30f142a0b7beeca9b7546c4197cf96fc2aed960392`。语料SHA256、各轮耗时及全部参数也在原始数据中，最终公开指纹为`1ilzgj0:7901`。

其余是调度、计数等开销。只减少正式落子耗时，对当前教师自对弈的整体速度帮助有限；教师内部仍包含大量引擎调用，需进一步剖析才能分清候选、规则模拟与评分各自的成本。

若局面分布和预算保持接近本次样本，100万条教师命令单进程粗算需约34–47小时；实际生成训练文件还要加入IO。更高教师预算、更长对局或复杂后期可能改变这个估算，几万至几十万局不能直接视为一次很短的本地任务。先生成小数据集验证学习效果，再扩大采样规模。

主进程峰值RSS约177MiB，未统计四个子进程的合计峰值，也没有加载神经网络。

## 如何理解吞吐

`TrainingEnvironment.step`仍使用完整applyCommand和真实规则随机数，并校验操作者及命令结构。性能收益主要来自常驻局面、不保留60步悔棋历史、不每步序列化存档，以及按需返回观察；没有关闭技能、死亡反应或规则事件生成。

直接引擎和训练环境的差异较小，后者包含权限/参数校验及额外计数。Session对照还包含JSON序列化，但没有磁盘IO或完整教师trace，因此这里的比值只适用于所测包装开销。

随机模拟从公开观察构造独立局面，再执行规则并返回公开观察，会额外复制数据。动作描述需要检查各类能力；逐个参数组合的预检还会增加成本。二者都不能用最快的空棋盘applyCommand结果代替。

教师的`simulations`是现有搜索计数，不是未来MCTS访问次数，也不覆盖全部候选生成、几何查询、规则预检和评分工作。即使教师调用占绝大部分时间，也不能仅据此断定其内部是评分、复制还是规则模拟最贵。

## 后续优化顺序

1. 保留TypeScript引擎，用独立常驻Node进程并行采样；先测2/4进程教师与未来MCTS的端到端吞吐，再决定进程数。
2. 将搜索热循环留在规则进程内，网络评估请求做小批量合并；避免每个搜索节点都通过JSONL来回传输整份观察。
3. 对真实搜索剖析候选生成、几何查询、状态复制、评分和网络等待，再有针对性地缓存、减少重复查询或改编码。
4. 先测约12M网络在浏览器CPU/WebGPU的实际加载、推理、峰值内存及搜索后整回合等待，再投入长期训练。Node规则吞吐不能预测这些指标。
5. 只有在实际目标吞吐下确认规则转移持续成为瓶颈，再评估局部数据布局优化或原生/WASM实现；迁移须继续通过概率、反应、不可变性与历史回放验证。

不应把开局或短回放性能直接外推到大量克隆、长反应链、复杂路径和多层状态的最坏局面。4进程结果只验证独立规则环境的扩展性，未验证教师、网络训练或GPU推理的线性加速。
