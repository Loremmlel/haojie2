# AI 与训练状态

更新：2026-10-24。

训练系统使用独立 **C++ / LibTorch 宿主 + Rust 规则 actor**。模型、激活、梯度和补偿优化器保持 BF16；身份、索引、顺序和存在位采用整数/布尔。生产运行路径已移除 Python 包、旧学习器、GRU 历史回放、长根权重租约和旧控制入口。

模型主干恢复为宽 384、6 层、6 头、FFN 1536 的 Transformer；策略头使用上下文与候选的非线性交互。此前 113.9 万参数的 MLP 已撤回，其测量仅保留在历史记录中。

就绪对局进入全局 FIFO 并合批，CPU lane 逐局推进；结果释放 GPU 提交锁后立即回送。根表仅在换根时传递，推理根缓存随参数发布失效；学习批按根/候选去重，一次前向与一次反向。连续同席位轨迹保留实际行为概率及真实奖励，完整路径和逐层排除 frontier 保留搜索信息。

支持在线扩缩容、零并发停放、手动/定时保存、停止和恢复。停放释放规则树和推理缓存，恢复继续原局；检查点包含未决转换、部分轨迹和未消费块。窗口计数、退出排空和恢复后的累计数据分别记录。
