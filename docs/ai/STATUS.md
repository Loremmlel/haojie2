# AI 与训练状态

更新：2026-10-24。

训练系统使用独立 **C++ / LibTorch 宿主 + Rust 规则 actor**。模型、激活、梯度和补偿优化器保持 BF16；身份、索引、顺序和存在位采用整数/布尔。生产运行路径已移除 Python 包、旧学习器、GRU 历史回放、长根权重租约和旧控制入口。

模型主干为宽 384、6 层、6 头、FFN 1536 的 Transformer；当前整组实现 15,184,130 参数，使用 query/key GELU 评分。此前 113.9 万参数的 MLP 已撤回，其测量仅保留在历史记录中。

当前实现贯通类型化全局/实体/候选表、绑定 key 缓存、lane 内解码推进与切块、独立根请求/回送及完整学习图。最后一组共同替换整包根输出、覆盖式梯度和两遍 BF16 更新，并修正 CPU 后台保存的优化器快照共享。保持完整 Transformer、真实行为概率和奖励、v3 共享对象检查点；超容量执行同一完整学习器。详见[决策记录](../../training/native/architecture/DECISION.md)。

最后一组 `packed-handoff` 使用 12 并发、20 秒、学习 batch 32：正式命令 14,379，main 为 5,324，窗口命令吞吐约 **2.70 倍**；实际消费 27,168 个连续转换、849 次更新，完整墙钟 22.72 对 26.33 秒。原生窗口末 ready 21,294、partial 79，显存采样峰值 4,488 MiB。main 短窗尚无终局消费，两种训练单位分别记录。

同一 4,096 转换、128 次更新的 1/2/4/8/12 短曲线已完成，1→2 斜率仅 **0.390**，扩展目标没有达到；12 并发完整进程为 7.403 秒，此前 device-learning 的同 batch 32 对照为 7.000 秒。按作者要求，本组测量后停止继续优化与评测。生产默认 batch 512，本机示例和短测显式使用 32、推理上限 12。

支持在线扩缩容、零并发停放、手动/定时保存、停止和恢复。停放释放规则树和推理缓存，恢复继续原局；检查点包含未决转换、部分轨迹和未消费块。窗口计数、退出排空和恢复后的累计数据分别记录。
