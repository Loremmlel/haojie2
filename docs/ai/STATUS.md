## 内核重写冻结验收与限制

无 Node 隔离环境完成独立构建安装，经典/神龛真实终局采样、非空监督、0→2→4 次更新、参数变化、有限优化器状态、另进程恢复及新权重再采样。恢复结果与连续四步训练逐张量相等。支持完整学习阶段恢复，不支持半局递归栈精确恢复。

最小原生主线使用已执行动作监督与真实终局价值；不是策略梯度或搜索访问分布训练。默认 11.7M 模型和 CUDA 路径另做功能验证；XPU 未验证。没有证明棋力提升，也没有获得长期扩训依据。

当前默认内核采用数值实体定位、类型化热字段/命令、公开只读视图、直接候选与编码、共同空间查询和分支提交；移动、攻击、伤害/死亡/反应、生成/复活、技能/法术、合成、神龛与时钟均接到同一表示。TS 显式复制/写入前分离与 Rust 实体 Rc 属于所有权机制差别，没有规则或采样算法分叉。

同机 111 局面、每段 8 命令、预热后交错五轮，完整引擎工作层成对加速中位数 TS 1.386×、Rust 2.736×。实际 151,938 参数 CPU 模型、并发 4、固定 12 个开中晚盘前缀的采样/记录/审核/准备/两步更新/评估完整链，三轮为 1.222/1.307/1.676×。采样单项波动，未证明稳定提速；完整链收益主要来自审核和准备。没有 GPU 或长期训练加速结论，不与此前就绪调度的历史倍率相乘。

冻结旧 TS 全规则差分、双端 1,101 夹具/5,376 动作节点、四场自然完整对局共 28,427 命令通过。Node 不在 PATH 时再次通过真实模型更新/恢复闭环。415 项 TS、26 项 Python（无跳过）、5 项 Rust、格式/类型/构建/发行一致性/目录/规则包/Clippy 及离线游戏、联机、图鉴、AI、特效、神龛和反馈专项通过；根 `index.html` 已本地更新，远端 CI 未运行。清理历史边界另见[清理记录](../maintenance/CLEANUP-2026-10-03.md)。
