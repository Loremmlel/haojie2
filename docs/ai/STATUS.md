Rust 的独占 CPU 周期进一步分解如下。分母是八个原生线程的 CPU 周期合计，与上面的 GPU 主线程时间分开统计。

| -------------- | -----------: | ---------------------------------------- |
| 几何特征       | 40.28–40.99% | 实体对的距离、攻击路径、遮挡和合法性查询 |
| 合法动作解码   | 30.19–30.76% | 构造合法来源／动作／参数前缀域           |

| 状态键         |   5.94–6.03% | 转置及缓存查询用局面键                   |
| 正式规则执行   |   1.20–1.24% | 实际命令推进                             |
| 纯搜索控制     |   0.20–0.22% | 排除规则、解码与编码后的树控制           |

因此，规则相关 CPU 成本集中在**几何与合法性查询**，命令执行占比较小；搜索控制本身也很轻。若继续改进，优先处理推理侧 CPU 执行和提交组织，再处理原生几何与合法动作查询。全程原生线程等待时间包含收尾阶段，此处只使用预热后、待分配窗口尚未耗尽的计数差值判断供给。
