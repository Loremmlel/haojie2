# AI 与训练状态

训练使用独立 C++ / LibTorch 宿主与 Rust 规则 actor；运行不依赖 Python 或 Node。主干固定为 384 宽、6 层、6 头、FFN 1536，完整保留 BF16、公开信息、真实行为概率与检查点语义。

正式训练采用完整终局 V-trace：真实胜负沿整局反向递推，按显存计算小批汇总梯度，一次提交更新。修复 BF16 策略归一化的伪梯度与 tanh 输出舍入导致的过早零梯度。完成局独立入队学习，学习与新局准入并行；移除按更新次数触发的全局排空。K=64 在消费时检查，已过期的未结束局提前释放；单局默认上限 262144 条己方转换，超长或内存压力下的未结束局整局淘汰，不补胜负、不参与学习。宿主自动预算不再封顶 8 GiB，达到预算 75% 时回收未结束轨迹或暂停采样等待完整终局学习。此前 `chunk=0` 的完整终局 v3 检查点可继续恢复，新档保留淘汰原因与上限；仍有效的未完成轨迹继续保存。v3 是数据格式标签，原短轨迹检查点仍只供测评，不能正式续训。

Colab 默认拉取 main、从头开始，按 CPU/GPU/空闲显存自动配置；保留 Web 面板、Drive 保存恢复、停止和手工／定期 AI 测评。本地已验证真实终局学习和数值修复，原始验收数见[功能验证](../../training/native/VALIDATION.md)。更新后的 L4 实际训练由 Colab 启动，性能实验未重启。

TS/Rust 公开动作树已用相同掩码跳过确定为空的最后一个固定参数前缀，原候选下标和完整合法叶子保留。多参数、材料和可延伸路径仍按原流程展开；恢复只刷新尚未采样的节点，不改历史输入和行为概率。冻结 BF16 模型的本地采样对照及积压量见[功能验证](../../training/native/VALIDATION.md)。
