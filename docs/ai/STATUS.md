# AI 与训练状态

更新：2026-10-24。

当前训练系统已切换为 **Rust 原生多局线程运行时 + 单 GPU 所有者 + 根编码缓存 + 分层解码 + 连续短轨迹 V-trace**。唯一训练入口是 `python -m haojie_training.online`。旧 Python 训练器、MC-Q、原生 `--training` 宿主、教师采样训练入口、旧控制台和旧 Colab 已移除。

Windows RTX 3060 Laptop 已完成真实 CUDA 自然对局短跑、在线扩缩容、停止保存和在途恢复；19 项新 Python 契约测试（含实际 CUDA 恢复与长根历史）通过，Linux CPU 独立安装后通过 16 项、跳过 3 项 CUDA 测试。按作者最新要求，本地验收聚焦正确性与新旧架构吞吐，不为极端环境增加专用调度；棋力留到 Colab 运行几十小时后评估。Colab L4 尚未实机验证。详细测量统一记录在[验收记录](../../training/online/VALIDATION.md)。

同机 64 局、120 秒自然新局对比：旧 v3 约 416.5 正式命令/秒，新系统边训练边采样约 157.9 命令/秒；新系统消费 20,736 个连续微步、更新 162 次，旧系统无终局、尚未更新。当前结论是采样推进较慢，短轨迹提前交付学习，内存减少。
