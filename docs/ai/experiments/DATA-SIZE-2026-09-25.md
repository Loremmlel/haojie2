# 按完整种子族的数据规模对照

接续[空间结构对照](SPATIAL-ABLATION-2026-09-25.md)。空间聚合改善训练拟合效率，但固定终点的验证收益在两个初始化之间不稳定。本轮固定原结构，只改变自然教师部署样本覆盖的完整种子族集合，检查当前范围内的数据规模趋势。

## 预先固定的协议

原2348个训练部署分步包含84个纠错分步，来自另外5族。本轮所有组统一排除这84例，只使用同一hard/800对medium/320配置下、已按hard教师筛选的自然对局部署数据，共2264例、23族、46条轨迹。原数据和纠错标签不修改；这是本轮各组共同的来源约束，不能将新全量组与前轮2348例组的差异单独归因于数据量或纠错质量。

训练使用原11,695,874参数`PolicyValueNet`，初始化20260922和20260923，各跑6/12/23族三组，共六次独立训练。均为6000次更新、batch 32、学习率1e-4、长度桶256、CUDA BF16训练和FP32评分，价值权重0；部署价值遮罩全部为False。初始参数哈希与前轮同种子一致，复用正式训练器与采样器，不使用空间实验结构。

共同评估点为0/250/500/1000/2000/4000/6000，另加各自的32次名义曝光点，全部采用完整子集和FP32；不按验证挑最好步数。保存32次曝光、2000步、6000步检查点及完整优化/随机状态。检查点为`haojie-data-size-checkpoint-v1`独立格式，防止部署专项被当作完整策略加载。

## 验证与来源边界

验证仍是原504个部署分步、原5个种子族，整份验证文件不变。审计会单列未与最大自然教师池重复编码的固定验证子集，所有规模使用同一个补充比较分母，不按各自训练池重新挑验证样本。同时列出各验证族、操作者以及各规模重复编码数。

该验证已多次用于开发调查，不能视作未触碰的最终测试。数据规模与具体族组成相连，且只固定一条嵌套路径；即使趋势一致，也不能把它当作所有训练族抽样的统计定论，或外推到超过2264例的数据量。各组自然带来的席位、兵种及局面分布变化需要如实报告，不把它们隐藏为纯数量效应。

来源仍为`3.0-feedback5-live-deployment`、`haojie-entities-factorized-v1`。原索引及分片、正式Python源码、实验脚本绑定哈希，结束再次核对；不采新局、不改历史规则、轨迹、指纹或标签。没有新增终局/截断/中断对局，原游戏统计保留在来源报告中。

从原始结果元数据核对，本轮6/12/23族子集分别继承10/22/42条终局轨迹、2/2/4条截断轨迹，均为0中断；并非新增对局。12族和23族已经覆盖验证中全部“操作者＋兵种”组合，6族尚有9个验证例子的组合未见。组合覆盖不等于具体局面关系、路径和战术覆盖。

## 完成核对

六组正常退出，每组6000次真实更新，共36000次，无跳步。48个FP32曲线点、18个检查点及两个预定终点的12次重新加载复评全部通过；重载后的命中数相同，策略loss差值小于1e-4。参数、梯度和保存的Adam状态数值有限；每组6000步共192000次样本曝光，全部训练样本均被访问。两初始化在6/12/23族的最少单例曝光次数分别为213/97/55、214/107/52，不能将训练误差解释为没有抽到样本。

原训练/验证索引、114个二进制分片、15个原始来源文件、正式Python源码和运行脚本哈希匹配。验证仍是2026092401、2409、2410、2416、2417五族、504例，来源10局中8终局、2截断、0中断，与各训练子集无种子族交集；所有部署价值遮罩为False。12族与23族各含1个单候选训练例，保留原样；验证504例全部为多候选。正式加载器实际拒绝全部18个专项检查点。

设备为RTX 3060 Laptop，PyTorch 2.14.0+cu130 / CUDA 13.0；未启用全局确定性算法，不承诺跨运行位级复现。六组记录的优化区间耗时合计2115.77秒，约35.26分钟，不含加载、评估、保存与收尾审计，亦不作为各规模的纯吞吐对照。

产物在`artifacts/training/data-size-20260925/`：`protocol.json`保存固定配置、来源哈希和入选下标，`summary.json`保存全部曲线，`completion-audit.json`保存独立复核、逐族/席位指标与逐例配对变化；`run.log`、`audit.log`保留运行记录。`run.py`拒绝重复启动和覆盖已有协议。

## 结论与下一步

本轮支持的是有条件的数据覆盖收益，以及重复训练带来的明显过拟合。最大池也只有23个训练种子族，且只走一条嵌套路径，不能证明数据已经足够；但“只要增加相同来源数据并继续训练6000步就会稳定改善”没有得到支持。专项命中仍很低，教师落点也未被证明是唯一战术正确答案。

结合前轮：采样分配影响学习，空间结构改善拟合效率，数据覆盖与训练时长共同影响泛化；现有证据不能把问题归结成结构、数据、方法中的唯一一项。优先做固定23族、原结构和配对初始化/批次的训练方法对照，先验证一项明确的正则化是否减轻过度自信并改善固定终点与未重复子集表现，不同时换结构、加数据和挑最优停止点。有效后再回到完整混合策略训练，检查根动作、其他参数阶段和价值任务是否退化，最后使用新种子换边对战。教师落点的战术结果与等价动作仍需独立检查。

本轮只新增实验驱动、审计和文档，未修改正式训练器或游戏实现。文档格式、差异空白检查和目录结构检查通过；未以此声称新增游戏行为、浏览器或实战验收。本轮无新增对战、不升级发行模型、不提交或推送，也未创建自动化；部署拟合不是完整策略棋力或对作者胜率。
