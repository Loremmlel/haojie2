## 已完成的败局诊断

完整败局共有1623个网络决策，其中1241个需要推理；0暂停，0次达到节点/推理上限，共6770次空分支回溯。回溯是动作树允许的行为，不能直接当作错误；也不能把所有返回的end都说成模型根节点最偏好的动作。

30处学生重推理全部复现；两档教师共60条命令全部被同一动作树覆盖。两档教师在30处的最终命令完全相同，所以在这些位置加倍教师预算没有改变标签。教师与学生完整命令一致9/30：首次部署0/10、局中1/10、末段8/10。21处分歧的第一处分叉为落点12处、根动作9处。教师选项在该处分叉的模型排名为第2–67，说明这些分歧中教师动作没有被学生候选生成遗漏，而是排序/贪心解码路径不同。它不证明教师是最优，也不排除未抽查位置的候选问题或教师自身的裁剪/估值缺陷。

首次部署10处中，学生9处选择第9列，另外1处第8列。全部246次部署里第9列58次、第8列46次、第7列55次；不能将首次部署偏向推广成每步都只选最右列。原1000步0.1模型同批种子的首次部署也集中于第7/8列，因此这个现象并非本轮纠错独有。

两个可复现例子：

- game 0、index 3：学生把杀手部署在(9,8)，两档教师均选(4,8)。game 2、index 3的定炮同样是学生(9,8)、教师(5,8)。候选存在，问题首先落在落点评分；还不能仅凭教师分数证明真实战术差距。
- game 0、index 178：学生把钩子移动到(9,13)，教师直接攻击敌方基地。独立精确单步转移显示攻击将敌方基地从230降到200，移动后仍为230，两者都没有未决反应。此处证明存在被低排的即时伤害机会，不证明移动在完整回合后必然更差；教师攻击根选项被模型排第6/9，概率约5.22%。

game 5、index 591的学生最终end经过13次回溯，根节点最高分实际是攻击分支；教师选择给单位装备寒冰法杖。装备与end的单步局面处于不同回合边界，不能直接比较它们的分数或把装备当作已证实能挽救败局。原始证据见`audit.json`、`audit-rows.jsonl`和`audit.mts`。
