# 部署采样分配的受控调查

接续[败局诊断](DIAGNOSTIC-2026-09-25.md)。问题是区分结构表达、数据覆盖与训练分配；现有64处可拟合结果只能证明小样本表达能力，不能证明泛化充分。实验产物目录`artifacts/training/sampling-20260925/`。

## 预先固定的条件

- 相同原扩量数据：47152个训练分步、2348个部署落点，原5族验证10530分步；不添加数据、不换验证划分、不改标签或规则。
- 11.7M原结构、初始化种子20260922和20260923，每种子两组，从头2000次更新；CUDA BF16、batch 32、学习率1e-4、价值权重0.1、长度桶256。训练后所有指标使用CUDA FP32。
- 自然组复用原采样器；部署组保留同一步自然批次的后24个样本，前8个位置用独立随机流抽取部署落点，池内仍按长度桶均匀抽样。每批总样本数不变，预期部署占比由4.98%升至约28.73%；实际上报抽样数、独立样本数和价值标签曝光。
- 只改变采样分配，不按验证表现选择概率。混合池改变批次最大长度，固定更新数/样本数并不等于相同算力或墙钟；部署参数没有价值标签，价值监督曝光也会降低，报告必须列明这些影响。
- 复用正式`Trainer`、`sample_indices`、`select_batch`和评估边界；实验驱动保存在`run.py`，检查点绑定脚本、输入数据和源码指纹。配对初始化参数SHA256必须相同，保留原产物。

## 判读边界

训练部署拟合低，说明不能只归因于缺少新数据；同数据重分配若改善拟合，支持训练方法/优化分配有影响。训练拟合显著提高但原验证不改善，则需继续区分数据覆盖、教师标签质量和结构泛化；仅凭这些结果不能直接指定其中一个根因。训练与验证都改善也不等于棋力提高，还需新种子实战及其他动作不退化。

同时报告根动作、部署、移动、目标、方向、策略loss和价值误差。部署命中指精确匹配教师落点，并不代表其他落点必然错误。两个初始化只用于初步重复性检查，不宣称统计定论。

## 数据和结构的独立核对

`data-audit.py`核对所有部署落点输入。训练2348例中有2327个不同编码输入，验证504例中有502个；两者各自均没有同输入冲突标签。验证有7例编码输入也出现在训练中，说明种子族隔离不保证每个简单局面都不同；维持原划分，报告此事实，不重挑验证集。此检查不证明编码字段已穷尽所有规则信息，也不评定教师是否最优。

只用训练标签拟合、在当前候选中选择最常见落点的基线如下。同分沿用候选顺序，兵种未见时回退席位频率（本验证无此情况），未按验证标签调参。

| 方法               |        训练部署命中 |       验证部署命中 |
| ------------------ | ------------------: | -----------------: |
| 席位与兵种频率     |  398/2348（16.95%） |    27/504（5.36%） |
| 仅席位频率         |   177/2348（7.54%） |    33/504（6.55%） |
| 候选均匀随机的期望 | 56.20/2348（2.39%） | 12.86/504（2.55%） |
| 原含纠错模型       |    72/2348（3.07%） |    22/504（4.37%） |

这进一步说明原网络的部署模仿训练不足以超过简单规律；但“兵种＋席位”的训练/验证差距也提醒我们数据覆盖、条件分布和泛化仍待查。不能只凭基线将问题归结为某一种因素。

代码检查显示：部署落点以候选x/y数值进入动作投影，来源指向手牌实体，无目标实体时目标指针使用全局token；候选评分拼接全局、来源、目标上下文和动作特征。实体主干可处理棋盘状态，但没有由候选格单独向周围实体查询的专门空间层。因此，“能记住64个局面”不等于“能用少量数据有效学会候选落点与敌友位置的关系”。这是结构学习效率的待检验假设，不是已定位的实现错误；当前不修改结构。

## 完成核验

四组于2026-09-25 12:31（UTC+8）全部完成，每组2000次实际优化更新，共8000次。`completion-audit.json`记录了检查点与报告一致、参数/梯度及保存的参数张量均有限、同种子配对初始参数SHA256一致、训练/验证输入与114个源分片SHA256一致，以及运行脚本和训练源码指纹未改变。所有组都保留原验证分组；没有重新采样游戏或修改历史轨迹、规则及标签。

每组均抽取64000个分步。下表中覆盖数是去重后的样本数，价值曝光是抽到有效价值标签的次数。

| 初始化   | 采样       | 全体覆盖 | 部署曝光 | 部署覆盖 / 2348 | 价值曝光 | 优化耗时（秒） |
| -------- | ---------- | -------: | -------: | --------------: | -------: | -------------: |
| 20260922 | 自然       |    33936 |     3078 |            1670 |    25786 |          94.05 |
| 20260922 | 部署重采样 |    30189 |    18348 |            2346 |    19407 |         135.29 |
| 20260923 | 自然       |    33928 |     3080 |            1670 |    25791 |          88.76 |

部署重采样增加部署曝光约6倍，但全体覆盖下降，价值标签曝光减少约25%，优化耗时增加约36%–44%。它改变了混合训练目标，未做重要性权重校正；这些不是相同算力下的收益对照。反事实纠错及部署参数的零价值遮罩保持原样，不为增加价值曝光补造标签。

## 完整FP32结果

部署训练集分母为2348、验证集为504；根动作准确率只计4746个多候选根动作。移动包含1515个样本，目标列只计1521个多候选目标，方向为1368个样本。阶段指标均在教师给定前缀下评估，不能当作完整命令准确率或实战胜率。

| 初始化 / 采样         |      训练部署 |    验证部署 | 验证根动作 | 验证移动 | 验证目标 | 验证方向 |
| --------------------- | ------------: | ----------: | ---------: | -------: | -------: | -------: |
| 20260922 / 自然       |   76（3.24%） | 23（4.56%） |     30.05% |   53.73% |   59.04% |   96.42% |
| 20260922 / 部署重采样 | 251（10.69%） | 30（5.95%） |     30.51% |   56.83% |   59.11% |   96.27% |
| 20260923 / 自然       |   69（2.94%） | 21（4.17%） |     30.91% |   54.19% |   58.25% |   96.27% |
| 20260923 / 部署重采样 | 250（10.65%） | 37（7.34%） |     29.41% |   57.76% |   58.97% |   96.49% |

| 初始化 / 采样         | 验证策略loss | 验证价值MSE | 验证终局等权MSE |
| --------------------- | -----------: | ----------: | --------------: |
| 20260922 / 自然       |      1.57688 |     0.48857 |         0.81163 |

训练分配确实是影响因素：两个初始化的训练部署命中均从约3%升至约10.7%，验证也同向提高。但验证只多命中7例和16例，未在两个初始化中都超过仅席位频率的6.55%基线；训练部署仍低于席位与兵种频率的16.95%。在几乎覆盖所有部署样本并重复曝光后仍拟合不足，不能将问题仅归因于从未抽到这些数据。

移动命中也同时改善，根动作则一组提高0.46个百分点、一组下降1.50个百分点，价值MSE两组都变差。减少价值曝光是需要控制的因素，但还涉及共享主干和目标权重，不能据此断言它是价值退化的唯一原因。本轮没有新增对战，不能宣称整体棋力增强。

复现限制：本轮20260922自然组与旧同配置候选的部署差异较小（训练76对72，验证23对22），但价值MSE差异明显（0.48857对0.83955），根动作也为30.05%对29.33%。不能将全部差异描述为小幅波动，也未查明其原因；驱动不同且未启用严格GPU确定性，不足以直接归咎于CUDA。当前比较限于本轮相同驱动的配对结果。两个初始化并非两套独立数据；`seed + step`的自然采样随机流还存在错一步重叠，不能当作充分独立重复实验。

## 对结构、数据和方法的判断与下一步

- **训练方法**：有直接干预证据支持采样分配影响部署学习，但当前重采样方案有其他任务代价，不能直接替换正式方案。
- **模型结构**：64例可拟合排除了“连这64例都表达不了”，没有排除全量拟合困难、空间关系学习效率或泛化问题。尚无结构对照，不能判定结构正确或错误。
- **数据量与覆盖**：数据固定时可改善，说明不能只靠缺数据解释；但原验证只有5个种子族，且简单频率基线也存在较大训练/验证差距，数据覆盖仍可能限制泛化。尚无受控数据规模曲线，不能确认加量能解决。

下一项优先做全部2348个训练部署样本的专项拟合学习曲线，保留原验证，在固定结构、批次和学习率下隔离多任务竞争，并保存多个更新点。若全量训练仍低，先检查优化、编码和结构；若训练显著提高而验证低，再比较数据规模与空间结构的受控消融。该实验只回答拟合与泛化，不作为完整策略候选。另需保留同配置复现差异调查，不能把增加步数后的改善直接称为结构或数据结论。
