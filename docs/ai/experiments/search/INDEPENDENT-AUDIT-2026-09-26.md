**2. 搜索把未覆盖阶段的未知估值设为0，制造了结束回合偏好。**

`bootstrap/policy.ts:174`在进入新召唤等窗口时直接返回0，play叶子则使用`0.25 * 网络价值`。`puct.ts`的外层搜索最多走两条原子命令，并在回合窗口切换时停止，不能完整比较双方的下一行动回合。

这使“继续行动”和“结束回合”接受不同处理。play预测为负时，结束回合可以通过进入未知窗口得到0；预测为正时，同一机制又可能鼓励留在play。这里的0没有被写成平局训练标签，但已经作为真实的搜索评分参与比较，足以改变策略。

本次沿原轨迹重放并精确复现了四处原模型决策。其中000轮selfplay-00的第93条命令，教师选技能，实际模型选end。保持局面、候选、模拟种子、预算全部不变，只替换网络叶值：

| 非终局网络叶值 | 选中的命令 | end估值 | 其他主要分支估值 |
| -------------- | ---------- | ------: | ---------------: |
| 恒为−0.25      | end        |       0 |            −0.25 |
| 恒为0          | 教师技能   |       0 |                0 |
| 恒为+0.25      | 教师技能   |       0 |            +0.25 |
| 实际父模型     | end        |       0 | 约−0.233至−0.249 |

000轮selfplay-01第3条命令也出现同样机制。常数模型没有判断动作好坏的能力，却能因为阶段处理改变选招，说明此处存在估值偏置；这不是已经证明每一次end都是错误行动。

原始14局中，有end及其他动作可选的搜索根，玩家1选end为186/260，玩家2为50/1326；把教师的非end改成end分别158次和2次。两席位遇到的局面不同，不能直接当作严格的对称实验，但与上述固定局面干预方向一致。

修复不能仅把0换成尚未在该阶段训练过的网络值。应统一候选的评估边界，或在无法公平比较的窗口明确回退教师；随后验证常数估值不会因为人为截断给某类命令额外收益，真实终局仍使用规则收益。

证据：[四处决策及常数对照](../../../../artifacts/training/independent-audit-20260926/search_probe.json)，实际检查点复现通过`assert.deepEqual`校验。

**3. 大部分搜索访问分布没有给出动作排序信号，策略学习也没有直接反馈到搜索。**

代码中的网络接入只读取`output.value`。候选来自easy/40教师，最多8个；PUCT探索项使用均匀先验`1.5 / 候选数`，没有读取网络策略概率。策略损失仍会更新共享主干、间接影响价值，因而不能说网络完全没有学习反馈；但这里没有“学到更好的策略概率，再用它引导下一轮搜索”的路径。

直接读取14局原始压缩记录，重新得到：

| 项目                         |                   数量 |
| ---------------------------- | ---------------------: |
| 全部命令                     |                  22491 |
| 搜索根                       |                  12221 |
| 有多个候选的搜索根           |                  11562 |
| 访问次数在所有候选间完全均匀 | 9531，占多候选根82.43% |
| 选招与教师首选不同           | 9553，占多候选根82.62% |

在000轮selfplay-01第23条命令，八个候选各访问两次，教师攻击被改成部署；胜出部署与教师攻击的根值只差约0.000021875。将叶值替换为0或任一固定正负常数后，都恢复教师攻击。另一处第67条命令也被同样方式改选，八候选依然各访问两次。

这些现象不证明教师每次都更好，但证明外层搜索经常没有积累差异化的访问证据，只由尚未泛化的价值头的微小差异打破平局。保存下来的访问目标此时仍是均匀分布，并没有保存这一打破平局的排序依据。单纯继续拟合这样的目标，不足以产生预期的策略改进。

此外，连续数据组合只保留`step == 0`，丢弃目标、落点、方向等后续参数监督。对于部署等分步动作，根目标只覆盖动作及来源选择，不能训练落点。旧模仿阶段最薄弱的部署参数，因而也没有在这条自对弈链里继续得到直接训练。

这与[AlphaZero原论文](https://arxiv.org/html/1712.01815v1)中策略概率和价值共同引导搜索、搜索分布再监督策略的机制有实质差别。两命令、教师候选、均匀先验、价值接入是一个有范围限制的实验系统，不能期待仅增加运行轮数就复现完整策略迭代的效果。

证据：[原始记录计数及逐局拆分](../../../../artifacts/training/independent-audit-20260926/records_probe.json)；实现位置为`bootstrap/policy.ts:85`、`puct.ts:249`、`puct.ts:297`、`value-cycle/model.ts:18`、`continuous/dataset.py:79`及`:143`。

**4. 教师模仿先有关键动作欠拟合，强化专项后又出现明显过拟合。**

本次重新加载保留的模型和真实训练／验证张量，以CUDA FP32重新前向，没有复用旧报告的预测：

| 模型                     | 训练部署命中／2348 | 验证部署命中／504 |  验证NLL |
| ------------------------ | -----------------: | ----------------: | -------: |
| 原混合训练2000步         |          72，3.07% |         22，4.37% |  3.74567 |
| 部署专项6000步，初始化22 |       2032，86.54% |         36，7.14% | 16.01079 |
| 部署专项6000步，初始化23 |       1970，83.90% |         37，7.34% | 17.64660 |

原完整策略连训练部署都没有学好，不能只把最初失败归因于部署到新分布。延长专项训练能记住大部分训练样本，却不能稳定推广到新种子族；因此也不能用“再多训几步”解释后续失败。

这组数据支持的是任务分配、样本覆盖与表示的共同问题，并不能证明Transformer结构不适用。当前部署评分把候选坐标送入MLP，与共享全局及来源表示拼接，没有显式的候选位置—各棋子相对关系。它能表达复杂函数，不等于在约两千个高度相关的部署示范上能高效学会通用空间规律。已有空间实验只检验了一种局部聚合结构，不能据其结果排除所有空间归纳偏置。

教师标签是一个完整命令的一条分解路径。训练与现有分步验证都给定教师前缀；实际学生先自行选根，再贪心选参数，任一早期错误都会改变后续前缀和未来局面。整体分步准确率不是完整命令正确率，更不是完整对局能力。[DAgger论文](https://proceedings.mlr.press/v15/ross11a.html)讨论的正是动作会改变后续数据分布的问题；本项目做过少量学生局面重标，但165个纠错根的一次对照不足以证明已经解决或否定这类分布偏移。

精确匹配教师落点还会把等价或近似等价落点算错。因而部署准确率低是模仿能力证据，不能直接当作每个不同落点都造成战术损失的证据。后续需要完整命令评估和同一行动窗口的真实战术结果，不能仅换一个更好看的准确率指标。

证据：[本次部署前向重算](../../../../artifacts/training/independent-audit-20260926/policy_probe.json)；教师生成在`src/ai/training/teacher.ts`，分步监督在`scripts/training/encode.ts`，贪心推理在`src/ai/training/decoder.ts`。

**5. 工程门槛没有验证学习是否有效，轮次筛选也没有补上这一缺口。**

本次使用原人工局面、原两个模拟种子，分别给搜索提供恒为−0.25、0、+0.25的网络叶值。三个完全不判断局面的值函数都通过60/60人工战术门槛。该门槛能检查短程终局、反应及搜索正确性，无法筛掉当前的席位价值问题。原自然门槛又取已终局对局的最后一个决策，不能代替开局、部署、中盘和跨回合能力评估。

`continuous/dataset.py`的健康检查检查有限数值和32个已知根，未对泛化误差设有效性门槛。必须区分“参数不是NaN”“策略合法”“能拿到已经到手的短程胜局”和“能学到局势并把对局走到胜势”。

本次另从完成的原始对战`result.json`重新计数：候选对教师0胜12负2截断，父代对教师0胜10负3截断，候选对父代8胜12负7截断；另外两个截止中断没有完成结果文件，不补造胜负。候选不是同一个模型，换边种子也相关，不能合并成单一模型胜率，但这些结果没有提供有效改进证据。

所有八局都终局、候选至少拿到对父代四局中的三分，是保守开发筛选，不是根本原因；随意放宽门槛会接受噪声。真正缺的是在长跑前固定比较直接教师、同候选零值搜索、网络搜索，验证搜索增强确有收益。现在候选对父代的局部胜负只能说明两个弱而有偏的策略之间的变化。

**教师本身的质量仍需验证，但不是这次最先应归责的环节。**

hard教师是宽度2、配置深度7条原子动作的受限搜索，候选和对手回应受到裁剪；hard对medium的相近策略还可能共享盲区。原始37352条教师命令中有18619条标记为缓存命中，标签包含教师的计划连续性，而学生仅接收当前公开局面。需要另行审查教师在贴脸部署、远程风筝、行动时机等可达局面的决策，并比较冷计划与缓存计划；不能直接把one-hot标签当成唯一战术真值。

不过，教师上限不能解释混合学生对训练部署也只有3%命中，更不能解释同一easy教师加价值搜索后，被常数偏置大量改招。当前证据优先指向学生学习和搜索组合，尚无依据据此修改游戏平衡、断言教师整体不可用，或宣称换大模型即可解决。

**建议的处理顺序与验收条件。**

1. 先解决阶段估值不可比和无证据改招。固定自然局面、候选与预算，对比直接教师、零值搜索、当前网络搜索；记录动作变化、访问差异、真实短程战术损失和端到端成本。再用新的换边整局确认收益。若搜索不能稳定提供更好的决策，不进入下一轮采样。
2. 重建价值基准。原单终局验证保留作历史参照，另加入多个独立终局、覆盖两席位的胜负，按整局等权及阶段／终局距离报告；要求超过常数和席位基线，并测候选后继的相对排序及校准。训练池保留足够的历史终局，逐项比较抽样和窗口，而不是同时改全部设置。
3. 将教师模仿作为独立问题处理。先在已有教师候选域内检验完整命令排序与关键参数，明确哪些误差是教师等价动作、哪些真有战术代价；再补学生实际到达局面的教师示范。先证明小规模固定数据上的有效泛化，再比较容量、空间表示或规模。
4. 明确自对弈学什么。如果要学策略，就保留必要的参数监督，并让策略输出真正参与候选排序或先验；如果只研究价值，先做去除辅助策略损失的固定数据对照，避免把策略loss变化当作决策改善。每项只改变一个主要因素。
5. 达到上述门槛再做长跑。保留原始回放、规则边界、取消和数值检查；减少在尚未有效的候选上重复整晚采样与评测。七次候选训练与八小时流水线证明的是执行能力，不能替代学习效果验证。

本次没有启动新的完整对局或训练，因此尚未量化各缺陷修复后能提高多少棋力。已经直接验证的，是价值在新终局上的失准、搜索阶段偏置、访问目标缺乏区分、策略输出未直接使用，以及教师模仿的欠拟合／过拟合差距。这些足以支持先修正学习和搜索机制，再投入规模。
