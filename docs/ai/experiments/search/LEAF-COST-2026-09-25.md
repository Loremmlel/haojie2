# 搜索展开成本与叶端估值对照

本轮完成两次有界实验及独立复核。**可保留的改进是延迟新叶的完整命令枚举：小样本中配对耗时下降约15–19倍，零估值时选招和访问统计保持一致。直接套用教师手工评分则产生明显战术退化；补充父节点初值后只修复部分问题，尚不适合采集自对弈训练标签。** 没有训练或发布模型。

## 协议与范围

自然局面沿用[上一轮完整评估](../NATURAL-SEARCH-2026-09-25.md)的固定选择清单，按清单顺序取前四个不同种子族各自的第一个位置：

| 来源种子   | game / index | 完整根命令数 | 支持情况                 |
| ---------- | ------------ | ------------ | ------------------------ |
| 2026092591 | 0 / 233      | 166          | 支持                     |
| 2026092592 | 2 / 707      | 未枚举       | 回合外巨大化不支持，保留 |
| 2026092593 | 4 / 665      | 551          | 支持                     |
| 2026092594 | 6 / 32       | 166          | 支持                     |

这些族与原训练/验证隔离，但已用于开发，不是新盲测。来源10局仍完整重放，8终局、2截断、0中断；本轮没有新对局。另保留原30个人工战术夹具（5类×两操作者×3个横坐标）作短程规则参照，不能当作30个自然独立样本。

固定16模拟、2条完整命令深度、每次动作枚举512参数节点、均匀根命令先验，搜索种子2026092731/2026092732。四个工作进程按位置动态领取任务；每个位置内两个种子的变体执行顺序相反，减少固定热身顺序偏置。计时只用于记录，不参与预算或选招。所有方法保持公开Observation、独立模拟随机数、实际操作者方向与完整命令边界。

第一阶段预先固定三个方法：

- `eager-zero`：旧行为，新叶立即完整枚举后返回0估计。
- `deferred-zero`：新叶首次只返回0估计，第二次访问时才枚举；根仍完整枚举，不按教师分数裁剪。
- `deferred-heuristic`：延迟枚举，并使用`Math.tanh(evaluate(imagined(observation), rootActor) / 1000)`估计非终局叶。复用原公开局面的手工评分，1000是预先固定的缩放量，**不是校准过的胜率**；终局仍使用真实±1/0。

第二阶段是在看到手工估值退化后追加的探索性对照，不能冒称预注册确认：保留`deferred-heuristic`作重复基线，只将未访问边的默认值由0改为父节点的手工估计，记为`deferred-parent`。其他设置不变。

## 成本结果

第一阶段204条请求（34位置×2种子×3方法），并行计算阶段82.79秒。自然位置每方法8请求，6条返回合法命令、2条因同一未支持位置暂停。六个支持请求的原方法累计90.420秒，其中90.293秒用于动作枚举，约**99.86%**；规则转移仅约0.086秒。

| 自然位置           | 原枚举耗时范围（秒） | 延迟枚举耗时范围（秒） | 两个种子的配对耗时比 |
| ------------------ | -------------------- | ---------------------- | -------------------- |
| game 0 / index 233 | 6.505–6.897          | 0.426–0.436            | 15.27–15.81          |
| game 4 / index 665 | 36.999–37.158        | 1.963–2.065            | 18.00–18.85          |
| game 6 / index 32  | 1.424–1.438          | 0.078–0.093            | 15.43–18.16          |

六请求累计耗时90.420→5.061秒，展开节点102→6；每条都是17次展开降为仅根节点一次。其原因是根分支数全部超过16模拟，新孩子没有再次被访问，提前生成其完整命令域完全没有用于选招。配对命令、根访问次数、机会结果数、边均值及转移数相同；这里只省去了本轮没有使用的动作枚举。

这是3个支持位置、两个相关搜索种子上的工程证据。时间为并行环境中的各请求墙钟计时，累计值不是整批墙钟或CPU时间；不外推为完整比赛提速、不声称四进程本身带来上述倍数。延迟枚举也可能改变“未访问子节点枚举超限”的触发时机，因此不承诺所有原本暂停的复杂局面具有完全相同失败覆盖。

## 叶端信号与战术退化

原/延迟零估计在6条支持的自然请求上仍不改变基线。手工估计在6/6产生不同的已访问边均值、5/6改变选招，但没有自然位置真值，**有信号或换招不等于更强**。

人工夹具使用两命令全宽概率参照（终局±1/0、未知边界0），不使用待测手工评分给自己打分。各方法每类12请求：

| 夹具                 | 延迟零估值 | 手工估值、未访问值0 | 手工估值、未访问值取父节点 |
| -------------------- | ---------- | ------------------- | -------------------------- |
| 一步获胜             | 12/12      | 5/12                | 12/12                      |
| 同方连续两次攻击     | 5/12       | 3/12                | 12/12                      |
| 随机获胜             | 12/12      | 6/12                | 0/12                       |
| 对手死亡反应陷阱     | 6/12       | 3/12                | 3/12                       |
| 反应转行动           | 12/12      | 12/12               | 12/12                      |
| 合计达到短程参照最优 | **47/60**  | **29/60**           | **39/60**                  |

原枚举零估值同样为47/60。累计短程遗憾值分别13、27、13；父节点初值恢复部分收益，但不构成整体优越性。统计是已知相关夹具上的选招检查，不是对战胜率，也不保证夹具的两命令目标等同于无限时域的真实胜率。

已定位的第一个失败机制：`same-player-two-attacks-p1-x5`、搜索种子2026092731首次抽到`end`，手工估计约0.969；其余未访问边默认0，全部16次访问锁在结束回合，没试任何获胜攻击。父节点初值对照消除了这个复现中的探索锁定，专门测试已覆盖；一步获胜和连续攻击也均恢复到12/12。

第二个问题仍在：手工局面优势不是期望终局回报。比如`chance-win-p1-x4`在父节点初值版本里仍给`end`约0.954，攻击边约0.87–0.91，虽已采到终局获胜也选择结束回合。它没有最大化本实验的短程终局目标；长程棋力又缺少独立证据，不能只靠调大/调小缩放量把这一估计称为可靠价值头。

第二阶段136条请求，并行计算阶段9.87秒。自然位置仍是每方法6返回/2暂停；父节点初值产生5/6可区分边值、3/6改变基线，但0个终局叶，不能据此判断比另外两个方法强。
