# 数据先行的监督学习方案

本设计回应用户对继续沿用价值自举路线的否定。目标保持为浏览器端侧神经网络结合搜索，对强人类胜率超过50%。当前只完成数据语义核查与方案设计，没有建立新数据集或训练新模型。

**主线改为：多来源局面库 → 独立质量标注 → 冻结监督数据集 → 完整动作评分网络 → 浏览器规则搜索 → 用实战错误补充下一版数据。** 首轮不依赖网络自举标签，不将现有隔夜自对弈直接续跑作为主实验。

**现有数据已经做了什么**

`records/replay.ts`验证规则版本、命令顺序、权限、前后指纹与终态。`prepare.py`按种子族划分数据，真实终局收益只赋给实际操作者的决策根，截断/中断没有伪造胜负。连续训练组合器拒绝重复决策和训练/验证族交叉。这些属于数据完整性和来源检查。

现有标注包括教师所选命令、同教师候选软排序、搜索访问次数和实际整局结果。`improvement/labels.ts`给教师原选择固定0.8基础质量，剩余0.2按同阶段教师分数的排序分配；这不是独立的动作质量评审。项目也有人工战术夹具和反事实研究，但尚未建立具有足够覆盖、独立验收的动作质量标注集。

因此不能断言根因是“完全没有清洗、没有标签”。需要检验的是：**标签是否对应要学的能力，标签质量是否足够，数据是否覆盖真实决策。** 整局输赢作为行为价值的蒙特卡洛监督是合理方法；它不是每个动作的优劣证明。真实胜局中的坏招、败局中的好招都可能存在，不能按整局输赢清洗动作。

**1. 对局生成只负责提供局面**

来源包括现有不同策略的轨迹、程序化生成并由引擎验证的战术局面、真实强人类的棋谱和局面纠错。人类资料只在实际获得时使用；不得把计划中的专家数据计入产物。

按阶段、局面复杂度、攻守任务、能力组合、可选行动数及来源进行覆盖统计。保留普通局面和难例，避免只选战术题。生成器不能只走当前网络或同一教师认可的路线。

清洗保留不可变原始层，在派生索引中进行：损坏/规则不符隔离；强制动作与策略选择分开；重复长轨迹限权；冲突标签复核；近似局面按族统计。只在证明语义等价后合并状态，不能忽略资源、反应、个人时钟和来源关系后合并标签。败局、罕见规则、巨大化和未解决局面不能为了提高完成率而删除。

先按完整来源族划分训练/验证/测试，再做派生、分支分析和增强。同一原局的所有分支、同一战术模板的变体进入同一侧。最终评测保持自然分布，训练中的限权/重采样权重单独记录。

**2. 标注必须说明证据和适用范围**

| 标签类别         | 获取方式                                       | 允许教给模型的内容                                           |
| ---------------- | ---------------------------------------------- | ------------------------------------------------------------ |
| 规则事实         | 引擎执行、完整概率枚举或明确标记的概率采样     | 合法性、资源消耗、真实伤害分布、反应、终局；不等同于长程好坏 |
| 可证明的战术关系 | 有界求解器给出终局证据、对手应对与概率边界     | 在声明条件下A优于B；未展开分支仍未知                         |
| 分析或专家偏好   | 较重离线分析、不同续弈策略交叉检查、强人类复核 | 带来源和不确定性的相对偏好；不声称数学最优或校准胜率         |
| 实际轨迹结果     | 原始完整对局                                   | 该行为策略下的一次真实结果；不能沿用到未执行动作             |

标注单位是一个公开局面及多个**完整合法候选命令**，而不是每条微操作都配一个唯一正确答案。可以标记A优于B、A与B相近、尚不能区分；未标注候选不能自动变成负例。局面允许多个好招，只记录证据支持的偏序。

每个标注保存来源局面引用、规则版本、操作者、候选、标注类型、分析预算、随机场景、续弈策略、时程、证据及未知原因。存档仍用可重放引用，不复制大批Observation JSON。搜索结果之间比较必须采用一致边界；未知不能填0，人工一致率不能冒充胜率置信度。

**3. 建立标注器，而不是继续使用easy40作为唯一裁判**

优先做可独立验证的局面：直接斩杀、必须处理的基地威胁、攻击与反伤、先后顺序、移动开行后部署、随机风险、强制反应和巨大化时机。题目可以来自自然局面或明确标记的程序化生成，各自统计。

短程求解必须明确区分完整合法域与候选子集。没有覆盖全部应对时，不能写“唯一防守”或“必胜”。有限时程内获胜概率也不自动等于整局胜率。

长程局面允许较高的离线预算，比较多种后续策略，保存争议而非按多数票强行认定。预算翻倍后的稳定性只是检查项，不是正确性证明。强人类可用时，优先复核争议与策略性难例；人类也可能错，意见保留来源。大语言模型可以提出候选和解释草稿，不能自行充当规则或棋力真值。

上次完整窗口反事实试验是一个可复用的分析工具，其固定easy40长续弈没有产出足够标签。新方案不以继续扩大那个标注器为默认答案。

**4. 模型改为学习完整动作之间的选择关系**

公开局面只编码一次，对完整候选动作共享编码后分别评分。第一版采用小模型和带未知遮罩的排序监督；不同时增加多个辅助头。规则事实先用于标注检查与覆盖统计。

可靠的相对标注用于排序，等价动作不被强迫分出唯一答案。来源不可靠的标签不能与可证明标签混为相同置信度。偏好分只负责候选优先级，不能直接当作胜率或跨阶段价值回传。

浏览器使用网络给候选排序，再用精确引擎做有预算的战术验证与对手应对。保留教师外的合法候选提议，测量候选遗漏；输入不暴露正式随机状态。只有后续数据足以校准动作价值时，才将预测用于概率价值回传。

这条路线把较昂贵的分析投入离线标注，把其中可泛化的决策知识压缩到端侧模型。网络与搜索仍需独立验证完整对局、取消、规则覆盖和离线性能。

**5. 先检验“标注质量是主要瓶颈”**

首批事前选择约100个跨对局/模板族的局面，冻结分层，测标注耗时、可证明/可比较比例、争议率和规则覆盖。所有未解决样本保留在分母。这个规模用于验证标注流程，不代表足以训练强棋力。

然后做两个分开的对照，避免同时改结构、数据来源和标签后归因：

1. **标注对照：** 固定局面、完整候选、模型、训练预算和评测，比较原教师偏好与新复核偏好；两臂使用相同可比较样本及监督形式。额外报告新标注覆盖不了的局面。评测答案来自保留的独立求解/复核，不能只测与新标注器是否一致。
2. **筛选对照：** 固定标注方法，比较自然抽样与按来源族限权、覆盖分层的训练；实际抽样分布和总预算公开。不能将丢弃困难数据产生的指标提升称作清洗收益。

若相同模型换成复核标签就在未见局面及相同预算整局中改善，才支持标注瓶颈。若仅在训练集改善，检查覆盖和泛化；若连可证明短程题都学不会，检查表示、候选与优化。若好标注根本生成不出来，当前瓶颈就是标注者能力，增加对局或清洗无法替代它。

通过后再扩大标注库，利用模型与标注器分歧挑选下一批题目，同时保留自然随机抽检。自对弈用于发现模型的新错误，所有新增监督仍经过独立标注；第一阶段不依赖TD自举或网络给自己证明正确。

**方法依据及真正的限制**

[ChessBench研究](https://arxiv.org/abs/2402.04494)使用Stockfish 16对棋谱局面标注合法动作与价值，再训练监督模型。这说明对局来源与动作质量标注可以分开；其规模和棋力结果不能转移到浩劫。

浩劫目前缺少经过验证的Stockfish级标注者。新设计的核心投入是建立“有限领域可证明、一般领域可复核”的标注能力，再测网络是否能泛化。筛选已有弱教师的输出不能保证创造超越教师的知识；目标胜率最终仍需冻结浏览器模型后与强人类验证。
