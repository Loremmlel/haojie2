# 从目标重新设计学习闭环：2026-09-26

后续用户明确要求重新设计数据与标注路线，新的主线提议见[数据先行的监督学习方案](DATASET-FIRST-2026-09-26.md)。本文保留已完成诊断和先前提议，不表示其训练路线已被用户接受。

目标以本次用户要求为准：**训练一个在浏览器端侧运行、神经网络结合搜索、对强人类胜率超过50%的策略。** 旧文档中的80%不是本轮门槛。经典模式先形成证据；神龛暗选需要独立的信息集与实战验收，不能用经典成绩代替。

审查基线为`cada9d8`及工作区已有的BREAKTHROUGH、COUNTERFACTUAL和隔夜验收材料。没有覆盖这些未提交工作。本文核对了实际代码、原始压缩轨迹与实验回执，并增加三个有界诊断；没有训练新模型或获得新的棋力成绩。

**建议将主线改成：状态价值网络驱动的规则搜索，从真实残局向前推进训练，形成持续的策略迭代；策略模仿暂时只承担冷启动或候选提议。** 当前最需要修正的是学习信号、学习器更新方式和计算分配。尚无证据要求推翻神经网络加搜索这个目标，也没有依据承诺这套新方案必然超过强人类。

第一项调用当前`scripts/training/search/puct.ts`，在真实引擎产生的8个合法、确定性移动上，注入严格递增的受控叶值。叶值是人为测试输入，不是真实棋局价值，不用于训练。

其余两个大分差对照也通过，全部9个配置的叶值、访问总数和输入不变断言通过。这证明在这些条件下，正确排序也可能在访问计数中丢失。它不证明实战中的网络叶值正确，也不证明直接用最大Q选招就会更强。当前平局保留候选顺序；隔夜冻结版本的平局处理不同，不能用本探针冒充旧版决策重算。

第二项检查价值评估的输入准备路径。当前`search/value-cycle/model.ts`为了计算一个价值，先创建`TrainingActionTree`并展开根，再调用`encodeDecision`；`model.py`的价值头实际只读取状态主干，候选评分属于另一条分支。

在上轮预先冻结的32个自然根上完整重放9,854条命令，比较原路径与直接`encodePosition`。32/32根的实体、种类和全局输入逐项完全相同。各路径预热后交错测5次，逐根取中位数再求和：原路径210.07ms，直接编码22.31ms，约9.42倍。这是本机单次诊断的**输入准备成本**，不含网络、搜索或网页，不能声称整步提速9.42倍。

这给出一个具体的工程切入点：价值查询可以与动作枚举、动作前缀解码分开。尚未修改正式实现。

**三、目前的根本错位**

1. **在模仿命令与学习赢棋之间，没有建立足够强的策略改进步骤。** 热教师依赖计划缓存，学生拟合逐参数命令；隔夜搜索又只从easy40至多8个候选中选择。大量访问目标实际上只反映预算分配。最新结构实验虽改了表示和解码，仍未完成一个有效的新学习闭环。
2. **浅搜索依赖价值外推，而价值主要来自少量长轨迹的结果回归。** 两条命令通常仍是同一方行动。局面输赢预测更准不等于新候选排序更准，单纯提高回归指标不能解决决策。
3. **把晋级失败同时当成学习停止。** 隔夜七次256步候选都重新从同一父模型出发。正式发行保留最强模型是正确的；研究学习器却不应因为一次小赛程未晋级就反复丢掉累计优化轨迹。这是本轮配置的事实，不表示所有带门槛的自对弈都会失败。
4. **用昂贵的弱教师套弱搜索，使独立经验很少。** 同一晚只有6个新终局，许多算力用于续弈、评测和重复处理。扩大矩阵乘法吞吐、再叠结构，无法直接改变这一点。
5. **完整游戏接口尚未进入学习环境。** 权威入口允许非active方巨大化；`decisionOwner`只代表通常的行动者，不能覆盖全部合法主动抢占。研究器遇任意u7就停止或回退。这个缺口正好大量发生在长续弈里，不能当成可忽略的异常。

这些因素可以同时存在。均匀标签不是全部实战失败的唯一原因；最新112局结构/解码比较也不能归因于隔夜某一个配置。已有工程校验值得保留，但完成更多回放、文档和局部战术验收，不会自动产生策略改进。

**四、上次方案需要修正的前提**

上次要求无网络的完整窗口选择器先产生终局改招增益，再批准学习排序器。这适合验证“能否蒸馏一个更强的现成规划器”。本次目标允许价值学习和搜索共同进步，未必存在一个廉价、无需学习就足够强的规划器。

继续要求每个自然根都由easy40续弈到终局，才允许学习，会把最缺的长程估值能力变成开始训练的先决条件。应保留独立实战晋级与真实结果标签的标准，同时允许一个明确标记为估计的自举学习目标。不能把这种估计写回真实胜负，也不能凭它降低发行门槛。

因此，下一轮的科学问题改为：**相同规则、候选与计算预算下，从短时程真实后果学到的状态价值，能否稳定改善未见局面的选择，并随着累计学习向更长时程迁移？** 不再重复测试“同一个弱续弈器多跑一些能否证明首步有效”。

**五、只选一条主线：先学价值，再让搜索产生更好的经验**

**状态价值与候选提议分开。** 第一版复用现有小型空间主干的规模，不启动新一轮架构竞赛。输入保留全部公开实体、叠放、手牌、状态、行动资源、反应和阶段，不能只压成会丢信息的棋盘图。价值输入不含动作前缀，不经过动作树；多个搜索叶批量编码和推理。策略头可暂时冻结，现有教师用于提出候选和保障合法续行。

价值学习用两种有明确身份的信号：

- 已结束轨迹的真实收益，依旧是终局标签。可利用所有实际决策阶段，而非只有支持搜索的play根。
- 当前学习策略产生的转移上，使用固定目标网络的多步/TD自举估计，将已学到的短程后果向前传播。学习目标必须记录来源、目标模型和视角；中断/截断仍然没有真实胜负，原`value_mask=False`不变。新估计走独立字段与损失，不伪装成终局数据。

在固定参考方视角下，非终局的一步TD目标可以写成`stop_gradient(V_target(next))`，终局用真实`z`；实际采用多步或lambda回传。若网络使用当前操作者视角，换视角必须按实际操作者变化处理，不能每个命令机械取负。最初不额外奖励“走子”“造成伤害”或“快结束”，避免把赢棋目标改成刷代理分数。自举也可能放大误差，因此独立终局和决策检查必须一直保留。

**从可重放的真实残局向前展开。** 从完整历史局面的最后1、2、4、8个实际行动窗口逐级向前取训练起点，同时始终保留从初始局面开始的对局。恢复的是完整合法状态，不缩棋盘、不删技能、不改血量、不提前揭示随机数。起点和全部分支继承原种子族，不能重新起名后跨训练/验证。先按整族划分，再选双方、阶段、终局距离和能力组合；选择规则在结果产生前确定。

残局的作用是缩短信号传播距离，让网络先学会兑现优势和避免近期失败。不能只保留发现胜招的局面，也不能把残局准确率当整局棋力。已有人工战术夹具继续用于规则与回传正确性，不能冒充独立自然残局集。

**搜索仍执行完整合法命令，但不锁死两条命令。** 使用同一引擎和独立模拟随机源；强制反应、召唤、部署及抢占有明确调度。比较相对收益时完成约定的同一行动边界，保留已完成的成对随机场景；预算中断的半回合不能混入分数。优先复用既有规划与缓存，建立叶值接缝，不平行复制一个技能引擎。

候选可以由教师、网络和合法随机提议组成，按预算逐步加入；必须记录被裁剪的域，并给教师名单外的动作探索机会。不能把八条教师候选称为完整动作空间。先测少量候选的价值排序；在这个信号有效前，不训练新的大策略解码器。

对巨大化，先把现有“命令之间可抢占、实际提交串行裁定”的权限与取消行为写成可测的研究调度契约。任何传给对方策略的信息都只能来自当前公开局面，不能让对方看到尚未提交的意图。若某种抢占时序尚未定义，不得悄悄改成只能回合开始使用；未覆盖项留在分母并限制结论范围。

**研究学习器持续更新，发行冠军独立保存。** 学习器保留权重与优化器轨迹，周期性冻结快照供采样；发行模型仍只在正式门槛通过后更换。使用当前/历史快照与固定教师作为对手池，分别报告成绩，避免只适应一个对手。数值错误或明确退化允许回滚调查，但不默认每256步回到最初权重。

**采样和策略教学使用不同计算额度。** 大多数对局快速完成，以获得更多独立终局；少数事前抽取的根用更高预算研究策略改进。不能继续把“为了覆盖候选而各访问两次”直接解释为应模仿的最佳策略。若后续学习策略头，再独立比较经过验证的搜索目标；不直接放大Q、不删掉均匀行来制造好看的指标。

这是一条价值驱动的策略迭代路线；TD、残局课程和稀疏高预算搜索是对三个具体障碍的处理，不意味着三者都已证明有效。实施顺序应保留对照，不能同时改变全部因素后把成功归给其中一个。

**六、下一轮的最小可证伪交付**

建议只批准一个上限为两天的研究切片，不直接开新的隔夜流水线。两天是工作预算，不是达到强人类水平的承诺。先完成A/B，再确定C的数据预算；超限应交付失败定位，不能继续堆配方。

| 顺序                  | 固定其他条件，只检验一件事                                               | 通过信号                                                                                   | 失败后的动作                                                 |
| --------------------- | ------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------ | ------------------------------------------------------------ |
| A：价值接口与规则覆盖 | 状态价值路径不枚举动作；补研究调度的巨大化/反应/阶段边界，复用已有规则   | 同输入数值一致；冻结自然分层没有因已知u7规则缺口而退出；成本分项可重现                     | 停在接口修复，不开始长训练                                   |
| B：短时程可学性       | 固定小模型、候选和搜索预算，比较零值、现有手工值、纯终局训练值；先不加TD | 在未见种子族上，真实短程后果与动作排序优于对照，且两次初始化方向一致；完成率和未知结果照录 | 检查表示、视角、候选覆盖和优化；若训练集也学不会，先定位实现 |

B可以从至少32个独立来源族的训练起点、16个新的验证族开始；每族多根只增加覆盖，不能当成独立样本。具体根数和分层在生成新结果前固定。这是实验设计建议，并非这些新族已经生成。

D先用16个新族作淘汰性小赛程；若不确定则扩展预先规划的样本，而不是看一次结果就宣称成功。策略、预算、对手和设备必须冻结。以完整对局的真实胜负评估实际选招，不以价值MSE或参数更新数替代。

不要求每个旧价值验证集的MSE都改善才让研究学习器继续。独立价值校准用于发现错误，最终接纳依据是实际决策和整局结果；发行仍须满足规则、工程和棋力门槛。

**七、浏览器和强人类如何真正约束方案**

训练时的研究搜索可以明显重于浏览器部署搜索；浏览器约束的是最终模型与决策成本，不要求用部署的小预算制造所有训练标签。两种预算始终分开报告。

先复用约20万参数级的小模型，测完整决策的CPU与WebGPU路径。再决定是否需要扩大或蒸馏。模型参数小不自动意味着快：动作树、输入准备、动态形状、通信和串行前向都可能主导延迟。上面的9.42倍只确定了一个局部接缝，不能替代网页测量。

建议暂以普通笔记本CPU、每次非缓存决策P95不超过1秒作为研发目标，再与使用体验核对；这是待测的建议值。保持固定work预算、可取消Worker、合法收尾和离线单HTML要求。必须测生产成品的file://冷启动、完整命令、密集局面、内存和打包体积；旧的本地HTTP前向基准不算交付。

easy40是早期排错门槛，生产hard是本地参照。两者的胜率都不能换算成强人类胜率。应尽早收集少量强人类完整棋谱供误差分析，明确哪些用于训练、哪些用于验收；不要等模型完全战胜自家教师才第一次观察人类如何利用它。

最终声明超过50%之前，明确强人类名单、对局模式、先后手分配、浏览器设备与预算，冻结模型，在独立完整赛程上估计胜率。字面胜率按胜局/完成对局计，和棋不能自动按半胜代替；截断与中断单列，并报告对全部安排对局的未知结果边界。按共享种子/会话相关性计算区间；95%下界超过50%才支持对应人群与条件下的声明。少量对作者成绩不能泛化成所有强人类。

本轮重算的36个旧教师终局和6个隔夜新终局，不能推算最终需要几天或多少局，也不是完整语料总数。先观察增加独立经验后，固定测试曲线是否持续上升，再估算本机成本；不拿围棋的千万局需求机械套用，也不凭两天失败否定可行性。

**八、外部方法支持与适用边界**

- [Tesauro：Temporal Difference Learning and TD-Gammon](https://bkgm.com/articles/tesauro/tdl.html)说明价值网络、TD与随机棋类自对弈可以结合，并不要求先模仿专家命令。双陆棋的动作与时程不同，其人类成绩不转移到浩劫。
- [TDLeaf](https://arxiv.org/abs/cs/9901001)研究将时间差分与棋树搜索结合，支持“学习估值、保留搜索”的方法方向；这里仍需重新处理随机、连续同方命令和反应。
- [Backplay](https://arxiv.org/abs/1807.06919)提供从示范轨迹后部向前构造课程的依据。本文采用真实规则的可重放起点；该论文不证明浩劫残局训练一定迁移到开局。
- [KataGo论文第3.1、3.2节](https://arxiv.org/html/1902.10565v5#S3)分别讨论策略/价值数据的计算分配，以及探索访问不直接等同于训练目标。这里借鉴原则，不照抄围棋预算、规模或收益。

这些是方法依据。推荐主线是结合本项目新诊断作出的工程判断；尚未完成其学习与实战验证。
