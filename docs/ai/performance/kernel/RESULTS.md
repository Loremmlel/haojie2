# 运行内核最终验收与测量

本轮保留新的默认运行内核。TS 与 Rust 均覆盖完整规则、连续决策和编码，采样/审核无需串联旧 JSON 内核。旧实现仅作为冻结参照；JS 特殊别名图及外部 JSON 输入保留明确兼容边界。规则、候选次序、采样随机流、模型与协议版本未变，没有保留语言专用算法分叉。

相对 `d6df36f975fbddf785b318d7a280e266ccd1cfe0`，最终无探针引擎工作层成对加速中位数为 **TS 1.386×、Rust 2.736×**；同一实际模型的完整采样/记录/审核/准备/更新/验证链为 **1.307×**。包含固定策略前向的整体引擎指标未达到 3×。以下给出全部轮次和边界，不采用较早版本更好看的数字。

## 实际替换的内容

- 普通对象/动态 Value 热字段改为明确的实体句柄、种类映射、类型化实体/效果/反应/时钟快照与命令；身份表共享布局，槽定位当前实体，避免每次重建拥有型实体映射。
- 公开白名单视图直接服务动作树、预检与编码，删除决策中的 `observe Value → State → Tree` 往返。视图不持有权威根、正式 RNG 或对方暗选的返回路径。
- 候选直接构造类型化命令，复用来源准备、单来源移动场、数字前驱攻击广搜和同次攻击预检结果。保留惰性组合、精确复杂规则、原候选次序与随机消耗。
- TS 删除通用 Proxy 图，采用已知结构的热实体复制和冷字段写入前分离；Rust 使用类型化实体 Rc 分支。两端接续成功运行局面，外部快照仍独立，非法失败仍不提交。
- 编码直接读取类型字段与预编译类别编号，保留行序/存在掩码/模型含义；原生同步发送缓冲复用。二进制协议、TinyPolicy 投影复用、就绪调度都属于基线，不计为本轮新成果。

文件与规则路径对应见 [ARCHITECTURE.md](ARCHITECTURE.md)。没有新建另一套数值规则源，也没有更换模型、绑定库或训练方法。

## A 层：完整引擎工作

Windows 11，AMD Ryzen 7 5800H，Node 22.23.2，Rust/Cargo 1.98.1 release。111 个固定局面，覆盖经典/神龛、开中晚盘、0–111 单位、稀疏/密集、叠放、多格、技能、反应、亡者与时钟。每个局面独立构造真实动作树、编码及采样，连续执行 8 条命令；每轮 888 命令、11,997 节点、2,156 次策略评估。没有省略候选或只回放预定命令。

## B 层：同一实际模型的完整链

## 被实验否定或修正的方案

1. TS 首版逐字段描述符与历史句柄表复制，三轮仅 0.622/0.620/0.601×，明显负收益，已删除。改成显式热实体复制与冷数据分离后转正；再次删除通用 Proxy、改为写入前分离后达到约 1.30×，最终为 1.386×。
2. 单来源移动场在紧凑复制版本上没有可辨别的整体增量（约 1.13× 前后），不单独归因其收益。数字攻击广搜通过 90,224 项精确旧路径/方向差分；两端保留共同查询结构。
3. Rust 类型化树首版约 1.58×；类型化实体约 2.13×；反应/时钟和空间查询版本约 2.3–2.46×；准备复用、效果和图鉴版本约 2.54–2.71×。最终用五轮 2.736×，不将阶段倍率相乘。
4. 分配探针发现缺失身份查询反复重建索引；双端修正后同一 201,220 次定位的 Rust 申请由 192,287 降到 73,291 次。这是残余剖析后的一次实质修订，次数只说明工作减少，不代替正式耗时。

没有为未实现的撤销日志、全 SoA 或固定槽布局写“收益不足”的结论。实际对照选择了适合当前规则访问的紧凑复制/实体共享；两端物理所有权不同，但没有规则、候选或采样算法分叉。
