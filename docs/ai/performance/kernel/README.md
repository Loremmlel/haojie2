## 共同设计

运行局面拥有类型化实体及稳定的数值句柄；有序实体集合保持规则遍历顺序，身份索引只负责定位。实体的热标量与嵌套历史分开复制，规则所需死亡、反应及时间快照有独立生命周期。只读公开视图通过白名单构造，不携带权威局面的反向引用、随机状态或对方暗选。

命令参数在内部保持类型化，从来源准备到候选、预检和结算共用类型与规则准备结果；仅在外部协议及记录边界转为 JSON。编码直接读公开类型字段，写入已有模型布局。分支比较显式结构复制与按实体共享，保留失败原子性及外部独立快照；不预设撤销日志优胜。

首先在 TS 接通运行局面 → 公开视图 → 候选/预检 → 移动/攻击及连锁结算 → 下一局面 → 编码，验证连续执行后迁移同一算法到 Rust，再覆盖所有其余命令。现有规则函数可以逐步迁入新表示，但默认热路径不得往返旧 JSON 状态。
