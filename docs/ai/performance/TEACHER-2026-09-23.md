# 教师采样几何优化与速度对照

本轮保持 `3.0-feedback5-live-deployment` 规则与教师策略不变，基线为 `89b8bf8`。9月22日40局的99.28分钟属于旧规则及不同局面分布，不能直接作为本轮优化前数据。

## 修改范围

- `cells` 对1×1和2×2直接生成新坐标，保留原逐行顺序和返回值独立性。
- 占位匹配直接检查整数格偏移；栈顶查询找到第一个成员后返回，不再展开所有棋子的占位数组。
- 部署碰撞与路径起点检查复用几何内部的占位判断。
- 实时部署行按棋子覆盖行直接计数，不再展开格子、映射行号和创建去重集合。

没有引入状态缓存，避免结算中可变工作副本造成旧占位或旧行权。没有改变预算、候选顺序、评分、随机分界、搜索深度或缓存计划策略，也没有降低教师难度。没有新增依赖。

## 测量方法

本机 Intel Core Ultra 5 225H，Node v22.23.1。优化前先将 `scripts/training/self-play.ts` 及依赖冻结成 ESM 模块；优化后以相同构建命令生成另一模块。测量脚本动态导入指定模块，因此后续源码编辑不会改变已冻结的基线。

每次测量是独立 Node 进程，使用真实 `runSelfPlay`、公开观察和 JSONL 写盘。单进程计时包含采样、序列化、轨迹摘要与流结束，不含模块加载；四进程的整批墙钟还包含子进程启动和加载。墙钟只作测量，不参与工作量或选招。测量期间未同时运行本任务的测试或构建；未锁定硬件频率，结果仍包含系统调度波动。

固定 classic、hard/800 对 medium/320、同种子交换席位，每局上限40个全局回合或600条命令。达到上限保留截断，不能以血量判胜。摘要 SHA-256 包含逐步观察、命令、命令后公开指纹、搜索统计和结果，仅剔除耗时。

四个进程分别负责种子 `2026092301–2026092304` 的一对换边对局，前后使用相同任务分配。共8局、2921条命令，7局真实终局，1局到达40回合上限；最长局596条命令，最多37枚棋子。没有中断或非法提交。

四进程仅做一次前后对照，单进程做了交错重复；两者均不是小时级热稳态或大样本性能保证。不同种子对的任务长度差异依然存在。本轮没有更换任务调度，也没有将吞吐提升混入动态调度的收益。不能把36.21%直接套到旧40局的99.28分钟；旧批次有更长、更密集的局面和不同规则。

## 等价性与验证

- 新旧实现对2921条采样命令和79条当前神龛CLI命令逐条比较，**3000次完整状态一致**，包括正式随机状态、事件和日志。
- 演示局全棋盘、两种体型、移动/部署共4680次落点检查一致。
- 新增占位栈顶、格间点、坐标返回值独立性及实时部署行验证；343项行为测试全部通过。TypeScript与目录结构检查通过。
- 全仓格式检查使用 `npm run format:check -- --end-of-line auto`，兼容既有Windows行尾；没有批量重写无关文件。
- `npm run deploy` 已更新根 `index.html`，发行物812773字节；`deploy:check` 确认与新构建逐字节一致，当前CLI的79条历史命令指纹全部匹配。
- 基础34项、AI、特效、神龛、feedback3/4及图鉴浏览器验收以离线 `file://` 通过，公开视图浏览器流程通过；Pages另外以本地HTTP检查子路径、持久化和嵌入隔离，全部通过。

这些结果验证本次几何优化在固定输入上的等价性和采样速度，不作为棋力提升或规则变更结论。优化自身不要求重标同规则语料；9月22日旧语料仍需按9月23日规则变化另行处理。

## 复现入口

在各版本源码下分别执行构建，产物使用不同文件名，不能覆盖旧基线：

```sh
npx esbuild scripts/training/self-play.ts --bundle --platform=node --format=esm --outfile=artifacts/training/perf-20260923/baseline.mjs
# 应用优化后，以相同参数构建 optimized.mjs
npx esbuild scripts/training/self-play.ts --bundle --platform=node --format=esm --outfile=artifacts/training/perf-20260923/optimized.mjs
node scripts/training/performance/sample.mjs --module artifacts/training/perf-20260923/baseline.mjs --output artifacts/training/perf-20260923/baseline-1.json
node scripts/training/performance/sample.mjs --module artifacts/training/perf-20260923/optimized.mjs --output artifacts/training/perf-20260923/optimized-1.json
node scripts/training/performance/parallel.mjs artifacts/training/perf-20260923/baseline.mjs artifacts/training/perf-20260923/parallel-baseline
node scripts/training/performance/parallel.mjs artifacts/training/perf-20260923/optimized.mjs artifacts/training/perf-20260923/parallel-optimized
node scripts/training/performance/verify.mjs 89b8bf8 artifacts/training/perf-20260923/parallel-baseline/0.json.jsonl artifacts/training/perf-20260923/parallel-baseline/1.json.jsonl artifacts/training/perf-20260923/parallel-baseline/2.json.jsonl artifacts/training/perf-20260923/parallel-baseline/3.json.jsonl docs/playtests/current/cli-feedback5-20260923.jsonl
```

`verify.mjs` 只替换几何实现作差分，其他模块共用工作树，适用于本次仅修改几何的优化，不能当成任意两个规则版本的兼容性工具。它比较包括正式 `rng`、事件、日志的完整引擎状态，正式随机状态始终留在宿主，不送入教师。落点检查另覆盖演示局中所有棋子、两种尺寸、全棋盘和移动/部署两种语义。
