# TS 引擎优化：目标、计划与进度

最后更新：2026-09-27。状态：本阶段已完成。起点：`0690c93`。

## 目标与范围

最终产品目标仍是浏览器端侧运行的神经网络＋搜索，对强人类胜率超过50%，训练预算为现有机器累计30天。本文管理进入 Rust 移植前的 TS 优化工作；性能通过不等于经济性或棋力通过。

本阶段先在 TS 验证语言无关的算法与查询设计，后续 Rust 沿用相同规则、候选语义和模块职责。优化集中在已测出的动作查询/参数解码热点：上一轮轻量复制后，它们仍占两组短程采样墙钟的85.41%和88.99%。上一轮结论见[报告](../research/TS-ENGINE-PERF-2026-09-27.md)。

必须保持输入不可变、非法命令原子性、公开观察白名单、正式随机分界与消耗顺序、反应队列和存档行为。候选集合、顺序、参数分解、网络输入、固定工作量下的决策都属于性能改造的等价性约束。已知规则故障单独修复和记录，不能混在性能收益里或改写旧轨迹。

## 完成条件

1. 有冻结源码、固定工作量基准、候选/编码差分和完整状态回放，能复现前后结果。
2. 主要的重复复制/非法候选预检开销得到处理；查询与正式结算复用规则条件，不维护第二份近似规则。
3. 已测量至少三个主要成本假设，保留有端到端收益的改动。最后一次剖析后，没有尚未评估、可小范围实施且预计能改善整体耗时20%以上的明显问题。20%是本阶段工程收口尺度，不是模型训练可行性门槛。
4. 余下需全面改写状态存储、完整撤销日志或改变策略的项目明确列出，不为追求“没有任何优化空间”无限延长本阶段。
5. 格式、类型、行为测试、结构、构建、当前回放及离线浏览器验收通过；如有已知问题，给出准确状态和复现路径。
6. 最终报告同时列出相对本阶段起点、相对第一轮优化前的收益及未验证事项。完成后向用户报告，Rust 不在本阶段实施。

## 实验记录

本节随每次测量补充假设、结果、保留或放弃的理由。计时基准与行为验收分开运行；耗时不参与选招。所有生成物保存在独立的 `artifacts/training/` 子目录，源码与摘要位置在此登记。

1. 复制内部不重复递归/覆写标量字段：32个固定局面、3轮交错计时，采样中位耗时2139.34→1791.56ms，1.19倍；产物 `ts-query-20260927-copy/`。保留；整套优化已通过端到端验收，不能只凭复制微基准判定。
2. 非法候选提前拒绝：移动/攻击/部署/时钟相对第1项再快1.32倍（含剖析器，最终另测无剖析器）；产物 `ts-query-20260927-precheck/`。32局面的候选节点、完整编码及非法参数预检差分已通过，详细数量见产物 `query-summary.json`。节点遍历有128上限，不称作全动作树穷举。
3. 复活共有2106次预检，其中2099次非法，成为剩余最大热点。仅复制施法者投影继承资源，复用正式技能资格与复活条件后，相对第2项再快1.57倍；产物 `ts-query-20260927-revival/`。原生/继承技能与正式入口的差分行为测试通过。
4. 小屋反应每个落点都重新枚举全棋盘，且反复复制。同步只读预检器复用同一局面的小屋落点，正式入口共用资格判断，未修改候选域；相对第3项再快1.38倍，产物 `ts-query-20260927-batch/`。新局面必须新建预检器，无跨局缓存。
5. 几何搜索先用曼哈顿距离下界排除不可能路径，保留分数上限的原边界与相同最短路径顺序；相对第4项再快1.11倍（含剖析器）；产物 `ts-query-20260927-distance/`。此时32局面剖析中复制约19.65%、异常构造13.59%、攻击路径/路线合计约1.92%。随后扩大到128局面，检查是否只优化了局部热点。
6. 128局面扩大检查发现普通牵引3276次预检全部非法，献祭594次全部非法；将同样的共享准备扩展到这两项，再加速1.26倍，产物 `ts-query-20260927-skills/`。原生与继承版本均与正式命令入口比较全棋盘/列参数，通过。中间版本已完成71955条成功命令的完整状态差分。
7. 128局面的最新剖析中，轻量复制合计16.01%、`structuredClone` 4.86%、异常构造15.22%、攻击路径/方向约2.49%；其余分散在网络推理、特征编码、规则属性计算等。继续减少整体复制需要更大范围的状态共享/撤销或拆解全部结算，异常协议改造也超出本轮只读准备范围；尚无预计可小范围再提升整体20%的未处理项。进入最终无剖析器计时、端到端及发行验收。
8. 最终冻结 `ts-query-20260927-final/`：128局面、3轮交错、无剖析器，起点中位耗时6973.22ms，当前2625.64ms，**2.66倍**；3轮倍率2.45/2.70/2.79。采样动作、节点数、网络评估数、强制节点数和回溯数均相同。该数字是固定局面的单进程采样吞吐，不是正式训练速度。

## 收口结果

本阶段已完成，可以作为 Rust 等价移植的基线。保留上述六项性能改动与单独的反击故障修复；性能、行为、发行三类验收均通过。

| 相对本阶段起点 `0690c93` |  修改前 |  修改后 |  倍率 |
| ------------------------ | ------: | ------: | ----: |
| 固定128局面，3轮中位数   |  6.973s |  2.626s | 2.66× |
| 经典，自然开局1000命令   | 29.131s | 14.076s | 2.07× |
| 神龛，自然开局1000命令   | 53.456s | 21.029s | 2.54× |

| 相对两轮优化前 | 原始版本 | 当前版本 | 累计倍率 |
| -------------- | -------: | -------: | -------: |
| 经典，1000命令 |  51.777s |  14.560s |    3.56× |
| 神龛，1000命令 |  99.021s |  21.793s |    4.54× |

累计对照也逐条匹配完整轨迹与终态，产物 `artifacts/training/ts-query-20260927-total/`。每模式端到端对照只运行一次，需按短程结果理解；两次当前版本耗时不同反映运行波动。固定局面使用3轮中位数。机器为 Ryzen 7 5800H、32GiB RAM、Node 22.23.2，未混入 GPU 训练或并发基准。

端到端包含公开观察、动作树、编码、12929参数小网络、独立采样、实际结算、指纹和压缩记录。每组前后完整命令轨迹及终态一致；经典停在52 ply、神龛41 ply，均为命令上限截断，`returns=null`。这些时间不包含 GPU 优化器，不估计完整对局终局率或强人类胜率。源码、SHA-256 清单、计时和记录见 `artifacts/training/ts-query-20260927-final/`。

本轮没有修改策略评分、搜索预算、候选剪枝或网络结构，也没有开始 Rust 重写。后续 Rust 可沿用“只读准备→独立副本结算→公开随机边界”和同一局面查询批次的设计；语言层面的紧凑存储、所有权、并行调度另测，不能改变规则、遍历顺序或随机消耗来换速度。

### 停止点与后续计划

- TS 阶段到此收口。剩余成本已分散；继续采用共享只读查询的设计有维护价值，但没有尚未评估、预计可通过小范围改动再提升整体20%的明显热点。该判断来自上述样本和剖析，不表示 TS 已达到性能上限。
- 全面原地模拟/撤销、结构化状态存储、无异常的验证协议、候选分解或网络修改留给独立阶段。前三项要另测复杂度与收益，后两项会改变策略问题，不能夹带在等价移植中。
- 下一步先做 Rust 有限范围的吞吐与逐命令差分原型，使用本次冻结 TS 作为参照，验证收益后再扩大覆盖。浏览器继续使用 TS；查询/结算的规则设计同步维护，语言内部表示可以不同。
- 未复测8进程长期采样、GPU优化器和完整训练闭环。因此原30天经济性结果尚未改判，强人类胜率目标仍未验证；不能将单进程短程3.56/4.54倍加速直接当作训练时间缩短比例。
