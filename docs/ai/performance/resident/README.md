# 常驻自对弈采样与 30 天产能验收

2026-10-04，从已核对的远端 `main=903de3c` 干净工作区建立独立分支 `codex/resident-selfplay`。实现、自然局采样、单遍审核及一次短更新成本测量均已收尾。

**96 个独立任务得到 84 个审核有效自然终局，纯采样 84.11 局/小时，计入串行审核准备为 62.94 局/小时。** 按相同初始化策略、局长分布及机器负载外推，30 天分别约 60,561 / 45,317 局；预留 20% 时间后约 36,253 局。百万局未达到，串行数据产能差约 22.07 倍。全量保存分片还需要约 40.62 TB/月，当前空闲磁盘仅约 719.38 GB，按实测成本可再保留约 799 局；不能把算力外推当成现有磁盘可交付的数据量。

逐局、逐尝试、资源趋势汇总及未四舍五入公式见 [results.json](results.json)。两次具体缺陷、原始失败成本和修复依据见[失败与修复记录](INITIAL-FAILURE.md)。本报告不证明训练有效性或棋力变化。

## 冻结配置与实现边界

- Ryzen 7 5800H（8 核 16 线程）、32 GB 内存、RTX 3060 Laptop 6 GB；驱动 610.88、PyTorch 2.14.0+cu130。正式采样仅测该 GPU。
- 固定原初始化默认模型，11,695,874 参数，`artifacts/engine-20261003/model-default-initial.pt`；SHA256 `3b4b39edac99743170303855c7314244c2b1937ac22a7b0423a9f7913d5915ea`。CUDA FP32、主线程/interop 各 1，32 槽，按长度分组、零额外等待。
- 主种子 `2026100407`，任务编号从 0 开始、偶数经典/奇数神龛。游戏种子与策略随机源由版本化 SHA256 派生，不依赖槽位和完成顺序。正式任务全部自然开局，排错前缀不计产量。
- 目标 64 个自然终局或 3,600 秒总采样预算；达到目标停止分配，在原预算内排空。最后 120 秒停止分配、最后 5 秒取消剩余局。每局 20,000 命令、1,000 ply；解码仍为 4,096 节点、256 深度，未提高保护上限。
- 分母从导入 PyTorch 前开始，包含加载、填满、失败尝试、重跑、慢局及关闭。辅助持续窗口预先定义为每个连续运行段的 `[300, min(3300, 停止分配时刻))`，不倒选最快片段。
- 审核与采样串行；审核全部尝试，过期尝试不重复输出监督。每片 32 样本、读取队列 2 帧，确认记录完成凭据和来源哈希后逐片发布。没有假设审核与采样完全重叠。

复用 Rust 宿主外层循环，每局结束释放局面、递归上下文、观察、请求和节点缓存，保留允许复用的规则数据与缓冲容量。Python `Pool` 共用旧单批入口和新 `resident` 入口，每个采样服务只加载一次模型；单槽一请求，就绪队列容量为槽数的两倍，响应统计最多 4,096 项。请求校验进程代次、当前任务、跨局递增 ID 及模型哈希。

SQLite WAL 保存配置、任务、完成身份、尝试和运行账本，目录锁阻止双写；完成记录及时发布，任务数不在内存无限追加。半局恢复使用原种子和新尝试编号，旧前缀保留；发布完成但未收到回执的崩溃夹缝通过原生审核补记。偶发 EOF/断管仅重建该槽，单次运行最多两次；持续规则/协议错误中止，普通恢复拒绝错误账本及模型/引擎配置变化。审核积压保留在磁盘，`progress.json` 原子更新 `pending_attempts`，读取队列满时对原生编码施加背压；本次修复目录从 127 份待审降到 0。

本轮修复两个实际边界：公开 `uncertain` 候选被权威原子拒绝时，TS/Rust 同步沿既有 Gumbel 顺序继续，记录版本为 `model-gumbel-backtracking-v2`；固定解码预算耗尽则记 `decode-budget` 截断并补位。没有改规则、模型、成功路径采样排序或精度，没有把截断计为终局。旧 v1 记录仍可审核，详见失败记录。

## 推荐操作与复现

PowerShell 7，在仓库根目录运行。推荐 32 槽、CUDA FP32、零额外组批等待；模型文件沿用既有检查点，不覆盖。以下从新目录开始，终局目标可调大；`--tasks` 可限制任务身份总数。正常停止恢复可调整槽数、时间或目标，模型、主种子、规则和每局上限等身份配置须保持一致。

```powershell
$env:PYTHONPATH = 'training'
$env:PYTHONUTF8 = '1'
$py = 'training/.venv/Scripts/python.exe'
$engine = 'artifacts/resident-20261004/engine-budget.exe'
$model = 'artifacts/engine-20261003/model-default-initial.pt'
$out = 'artifacts/resident-next'
$sampling = @('--engine', $engine, '--threads', '1', 'resident', '--checkpoint', $model, '--output', $out, '--environments', '32', '--target', '64', '--seconds', '3600', '--drain-seconds', '120', '--seed', '2026100407', '--rules', 'mixed', '--commands', '20000', '--plies', '1000', '--device', 'cuda', '--precision', 'fp32')
& $py -m haojie_training.native @sampling
# 另一个终端请求停止；或在采样终端按 Ctrl+C。让在途局在剩余预算内收尾。
New-Item -ItemType File -Path "$out/STOP"
# 等进程关闭，再移除停止标记并恢复。若已达64终局，继续采样须把目标调大。
if (Test-Path -LiteralPath "$out/STOP") { Remove-Item -LiteralPath "$out/STOP" }
& $py -m haojie_training.native @sampling --resume
```
