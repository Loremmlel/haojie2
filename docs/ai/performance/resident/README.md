# 常驻自对弈采样与 30 天产能验收

2026-10-04，从远端 `main=903de3c` 的干净工作区建立独立分支 `codex/resident-selfplay`。
本轮只处理固定模型的持续采样、恢复和有效完整局产能，不训练或晋级行为模型。

## 预先冻结的验收口径

- 固定原初始化默认模型：11,695,874 参数，`artifacts/engine-20261003/model-default-initial.pt`，SHA256 `3b4b39edac99743170303855c7314244c2b1937ac22a7b0423a9f7913d5915ea`。
- CUDA FP32，PyTorch 主线程 1、interop 1，32 环境，按长度分组，零额外等待。
- 独立正式主种子 `2026100407`，稳定任务编号从 0 开始，偶数经典、奇数神龛；游戏种子和策略随机源由版本化 SHA256 派生。全部自然开局，不含前缀。
- 目标 64 个真实自然终局或 3,600 秒总采样预算；达到目标停止分配，允许在途局在原预算内排空。预算最后 120 秒停止分配，最后 5 秒发送取消，仍未结束则保留前缀。总账包含初始化、补位、慢局和排空。
- 每局最多 20,000 命令、1,000 ply；参数解码沿用原 4,096 节点、256 深度保护。所有截断、取消、错误和在途尾部均不计完整局。
- 主要分母为从启动到关闭所有采样子进程的总墙钟。辅助持续窗口预定为 `[300, min(3300, 停止分配时刻))` 秒；不足时如实缺省，不倒选最快片段。
- 审核与采样串行运行；原生单遍审核、每片 32 样本，确认原始字节和终局后逐片赋值并发布，按实测完整串行成本核算。
- 资源趋势每约 2 秒一行，工作池每约 5 秒一行；GPU 为包含桌面背景的整卡值，CPU 累积时间仅差分分析，不与墙钟相加。CPU 温度接口缺失时标记未采集。
- 不为凑 64 局或更好结论追加长测。仅具体实现错误或计时失真允许针对性复核。

## 实施记录

复用 Rust 宿主外层循环，局面、观察、树和策略随机源均为单局局部变量；规则目录与发送容量跨局复用。
Python 的 `Pool` 统一旧单批和新常驻入口；每槽独立进程、每槽最多一请求，任务编号不依赖调度。
模型只加载一次；接收队列容量为两倍槽数，响应窗口最多 4,096 项，完成记录即时落盘。
SQLite 保存不可变配置、任务、尝试及运行账本；进程锁阻止同时写同一输出目录。
半局以新尝试编号从原种子重跑，旧前缀保留；已完成身份不重复分配。发布文件和账本之间的崩溃夹缝通过原生审核补记。
EOF/断管最多重建两次；规则/协议错误直接中止。请求核对进程代次、独占槽位所属任务、检查点哈希与跨局递增 ID。

Rust 只增加回复中的 `commandIndex` / `ply` 进度标量，不改变张量、请求、规则、记录或采样算法。旧客户端忽略新增字段；旧引擎仍可短测，进度缺失显示 null。
