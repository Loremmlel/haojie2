## 顺序与边界

1. 转正：`native/engine/`、`haojie-engine`、构建身份与能力、独立交付包和原生 CI；完成验收及无探针对照后单独提交并冻结优化基线。

3. 记录：类型化规范哈希、成功提交的相邻哈希复用、写入；保留原哈希与提交语义。
4. 审核：内容及版本绑定的单遍审核编码；严格双审核与推荐流程分账。
5. 重测残余候选、属性、实体定位、预检、复制和析构，原型后差分、无探针交错计时，成立则接入。
6. 全套回归、实际模型与独立无 Node 更新/另进程恢复，交付复现入口、证据及残余成本。

模型、学习目标、搜索训练方法、Python 组批、GPU、优化器和长期训练不改。本轮不证明棋力提升，不合并 main、不发布包、不远程部署。
