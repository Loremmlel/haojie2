# 正式原生引擎与热点优化记录

本轮唯一任务记录。2026-10-03 从远端 `main` 的 `7cc64224a4fcc5188e9445bc16fe1058afa2d145`、干净工作区建立 `codex/native-engine-hotspots`。此前重写已在 main，旧报告中的未推送状态不再适用。实现冻结于 `040f393`；八个种子的冻结轨迹核对及两套远端 CI 已通过。按用户最后要求停止追加计时、整理提交交付，未完成项明确列于下文。证据均在 `artifacts/engine-20261003/`，下文目录名相对此根。

本轮只处理引擎、候选/公开视图、编码、记录/哈希/审核及直接出口。模型、学习目标、搜索训练方法、Python 组批、GPU、优化器和长期训练不改；两步更新与恢复仅用于回归。没有棋力提升结论，不合并 main、不发布包、不远程部署。

收尾限制：用户说明期间在观看直播，但后台负载起止、功耗和温度没有记录；所有倍率是本机交错观测值，不是受控空闲整机结果。模型实际为 CPU 单线程，不能直接把波动归因于显卡占用，也不能据此认定默认模型并发四的回退由引擎造成。用户要求不再追加后，已终止正在预热的 `final-single-pass-released` 及其自有进程树；默认模型并发四的追加两对未启动。原始完成轮次全部保留，不筛掉较慢结果。

## 残余成本与停止依据

A/B/C 后继续做了查询、候选尾部、实体/冷字段快照、连续行布局、容量/借用、预检事件、实体索引、路径和最终发送帧多轮原型。失败首版均修订或撤回，最后的简单增量已降至引擎约 1.6%、严格出口约 5.3%；最终直接基线对照仍显示累计收益，不能只由分配次数宣称提速。

独立探针 `final-profile/`（222 局面×2 命令）中，编码分配从转正基线 1,600,439 降至 334,665。以 A/B/C 后的剖析为残余组参照：属性 577,362→217,173、实体复制 663,713→189,537、路径 366,440→108,977。当前独占成本约：固定策略 277ms、编码 92ms、预检 92ms、候选 61ms、属性 57ms、路径 30ms、身份 27ms、实体复制 14ms。编码累计申请字节相对 A/B/C 后的 83.35MB 增到 102.38MB，预留容量减少次数不等于每项字节都下降，RSS 由正式测量另验。完整状态导出约 222ms、导入约 117ms 是开发边界，不能放大为生产热路径结论。探针时间不用于正式倍率。

固定长前缀出口 `final-data-profile/` 的主要残余为正式结算、编码和规则查询；协议墙钟含消费者背压，不是纯 Rust CPU。复杂增量状态哈希缓存没有引入，现有类型化流和提交复用已实际验证。

默认模型诊断 `default-model-profile/` 仍执行完整动作树：732 命令、15,365 节点、2,758 次编码、最大 421 实体 / 240 候选；采样 344.589 秒中，实际模型前向 336.793 秒（97.7%），整个严格链 375.450 秒。该轮带诊断，不代替最终无探针倍率。控制发送约 0.25 秒，解码约 3.79 秒，组批约 3.52 秒（各为被包围调用的诊断账，不能直接相加）。主要应用残余已在本轮保留的模型阶段。

同轮诊断的 24 次起点创建/前缀导入累计工作进程墙钟 3.713 秒（包含其中的结算；不可再与结算包含时间相加），50 次进程启动/握手累计 1.572 秒。各环境的累计推理等待为 838.192 秒，因为并发重叠，绝不能与 336.793 秒模型前向相加。正式引擎测量的完整请求中位 4.468→3.723 秒，包含另外约 0.77 秒的 JSON/导出/IPC 边界；开发完整状态导出探针另列，生产模型只接收公开编码。

跨命令增量编码、更细结算缓存等仍是未实现假说，不能称作已证伪或数学极限。下一阶段可使用上述固定权重、24 起点、真实前向次数/实体规模、严格与单遍分账重新剖析模型、组批、设备和数据加载；本轮不启动这些优化或训练研究。

单遍账使用 application 同一最终程序作为 baseline/candidate，并增加 `--single-pass-candidate`；其他输入与严格小模型并发 4 相同。功能复现为 `kernel/complete.ts`、`engine/hashes.ts`、原生 CI 及正式入口列出的检查。新种子完整列表与 `--known-interruptions` 只用于重现已登记 unknown，不允许忽略任意错误。源码交付包用 `scripts/training/native/pipeline/package.py`，自带规则、向量、测试和晚盘前缀，不依赖开发机丢失的 artifacts。
