# AI 完整复用优化（2026-09-23）

基线：`cec107917b840f9cb34954fa1635db58ccd2ae66`。按用户确认落地完整组合，而非仅保守组合；这是计算实现优化，不调整规则、评分权重、难度、固定工作量预算、存档格式或公开协议。

## 实现与边界

- 每次搜索持有独立的 `createStateKeys`，只缓存已结算且不再修改的内部快照。复用原始字符串键与指纹，不更换哈希或模拟随机种子；外部 `distribution` 默认保持原查询。
- 一次评估复用双方基地威胁和按单位对象身份记录的材料价值。同 ID 的位移／效果预览对象不命中原对象；不跨评估或状态修改复用。
- 单目标追击、新开放行部署只在最后一步下推过滤，保留后置过滤、中间 partial 截断、候选顺序及完整失败重试列表。
- 窄推演仅对优先级与落点无关的一步动作延迟落点评分。先确认候选非空，被采用后仍按原规则生成完整列表；不使用近似评分筛选组。
- `createPlacementQuery` 只服务同步只读批次，占位／独行侠／实时部署行索引不挂到可变 GameState。与权威 `canPlace` 共用规则，移动共用路径构造，保留等长路径顺序。修改状态后必须重建查询。
- 高频距离查询减少临时数组；连射排序预先计算分数，期望和风险共用结果分数。未削减搜索节点、束宽或对手回应。

固定 `work` 预算的行为以差分验收为准。相同毫秒限制的 `timed` 模式可能因完成更多搜索而换招，不承诺同墙钟预算的命令一致。当前验证不构成所有合法局面的形式化等价证明。
