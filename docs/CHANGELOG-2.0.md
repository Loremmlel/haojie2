# 浩劫2.0 · 文档核对与变更清单

依据：本次上传《浩劫.docx》，归档在`docs/source/`。旧代码基线：`6f7ef925cee688bb2f872db77683c8de46a11a00`。优先级：文末作者回复 > “浩劫2.0”明确修改 > 前半部分一般规则 > 旧版实施解释。没有用一般棋类常识替代这份规则。

## 一、名称

正式显示名称从“豪杰棋局 II”统一改为“浩劫 2.0”，覆盖页面标题、品牌、描述、规则、图鉴、演示说明、错误消息和导出文件名。旧版名称仅在兼容性错误说明中保留，说明为什么旧档不迁移。仓库`haojie2`不改名。

## 二、前半部分与旧描述的对照

| 项目                                   | 文档变化                                     | 代码处理                                                     |
| -------------------------------------- | -------------------------------------------- | ------------------------------------------------------------ |
| 棋盘、基地、起始部署行、每回合两次召唤 | 保持9×13、300血、1–8/6–13行等基础规则        | 保留；为了终极兑换把抽牌前的选择显式做成召唤阶段             |
| 第四属性                               | 不再是自由行动次数，而是选择攻击后的攻击次数 | 改为操作模式锁定、攻击序列与特殊额外操作分别计数             |
| 未特别说明的随从                       | 每回合只能选移动/攻击/技能中的一种           | 技能一次就是完整操作，不再按第四属性反复施法                 |
| 名刀                                   | 补充½移速的蓄力定义；回复明确名刀可以移动    | 0攻击次数只禁止普通攻击，不禁止移动；可先蓄力再移一格        |

| 其余普通编号                           | 五项基础数据及主要能力对应原描述             | 保留基础数据；统一适配新模式、金身及装备/沉默/中立等新增交互 |
