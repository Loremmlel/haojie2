# 3.0：神龛

基线：`ae797bf25cc7f25ad746a43662324c8a3ec4fe46`（2.5）。本次来源为作者2026-09-18提供的16神龛、新模式、新合成，以及随后对举旗坐标的更正。**举旗专属落点为(7,8)、(7,9)、(7,10)，全部按(列,行)解释**，不是(8,7)/(9,7)/(10,7)，也不自行改成中心三格。

发行号为3.0.0；存档schema、存储键继续为v2。经典模式保留原召唤经济；新增的普通10装备/友方单位攻击增益限制与牢千K配方适用于所有模式。不增加运行时依赖，不实现联机服务器。

## 对局流程与召唤

新对局先选经典/神龛规则，再选同屏/人机、难度及执先后。神龛对局第0回合双方分别从16种中抽取3个不重复候选；双方之间可以出现相同候选。双方可见对方候选、是否锁定，但仅可见自己的已锁定结果。双方都锁定后才一起揭示，包括玉碎奇偶；随后苍穹、赤焰依次入场，允许部署、装备、启用光环或保留储存。第0回合不允许战斗或正常召唤，入场完成才开始第1回合。

暗选命令接受明确的player，不强制等另一方先选。AI的Observation在揭示前剔除对方的选择与奇偶；AI先选、后选都不能读取它。当前同屏无法防止旁观操作或读取本机导出存档，界面明确提醒；这只是未来联网的可序列化命令与观察边界，不是已经实现的联网保密或防作弊协议。

神龛每个己方回合常驻两次免费终极召唤；回合开始的召唤窗口可另付3人头抽终极、2人头抽普通。合成、正常召唤与人头额外召唤的规则查询统一，不能通过非法命令部分支付。CX或其他能力给予的额外次数沿用该模式的默认池，但不算常驻两次；经典模式仍按旧规则处理。

老千K先掷一次1/3判定，抽4个或3个结果再选2个。每个克隆批次算一个结果，不能只拿其中一只、把余下克隆当作额外选择。该光环不复制到额外召唤。牢千K为**主动可选**：每实际己方回合一次，将一次合法抽取改为来源池的自选结果，不替代费用或额外增加次数。26普通编号或28终极编号就是自选范围；变体、其他合成与16神龛不额外加入，选择3、17、U12时直接得到其主形态，不再掷变体概率。抽取、改判、重新召唤及老千K候选遵循同一来源查询。

## 地标与永久光环

地标保存在独立的landmarks层，不挤占普通随从栈。一个地标上只容纳一个棋子；2×2棋子覆盖该格时也算占用者。地标存活时允许友方部署其上，阻止敌方部署；没有覆盖棋子时敌方仍可移动其上。休眠地标不阻止敌方部署。金晔仅能放在开局公共第6–8行；举旗采用作者更正的三个专属格，优先于一般公共三行限制。

不带穿透的攻击不能越过覆盖棋子直接选地标；有穿透的攻击按对应穿透规则处理。伤害法术穿透，区域法术可伤害同格随从层与地标层；不能为同格造成重复命中。地标射程0，只能选处于其上的敌方。作者属性中攻击次数为0、文字又允许地标攻击，本版以**每个己方回合一次主动同格攻击、不可移动**解释；这是实施解释，不冒充作者对攻击次数的追加确认。

地标归零后保留原格、暂停地标效果及光环，重建时清除旧临时效果，不产生普通阵亡、人头或死亡召唤。重建从被摧毁后的第一个己方回合开始计数，到达所需次数后检查该格；敌方或中立棋子占据时继续休眠，之后每个己方回合开始重试。重建不挤出占用者，不清除永久玩家光环。地标身份、休眠起点、已过回合、受阻状态均能保存、撤销与查看。

永久光环属于玩家，不占格，不是可被攻击、沉默或移除的棋子。神龛卡可永久储存；只有启用后对应光环生效。界面分别展示双方永久光环以及本回合是否使用时钟/牢千K。

## 组合技能与结算边界

以下未逐项说明处是延续既有规则的实施解释；后续作者回复优先。

### 强夺不是变身

保留强夺者的基础属性、编号、尺寸、神龛身份和位置；获取被击杀者的能力集合（包括其已取得能力），不把其伤势、加攻、当前蓄力、技能使用记录当作基础属性复制。首次获取一项能力拥有独立的初始使用记录；重复获取已消耗的一次能力不免费刷新。每项继承的蓄力/就绪资源与一次性/免费技能次数独立保存，避免磁暴一次蓄力同时给名刀、法师等多个技能付费。

UI、AI、战斗、回合开始/末、保护与死亡反应使用同一能力查询。主动技能按具体能力提交；冲撞、半速移动/攻击等资源也读取对应能力，而不是只改技能栏文案。继承法师能力可获得法师装备资格；不能强行取得不满足职业、禁止装备或生命上限条件的武器。武器仍只有一个槽，转移遵守相同替换规则。地标休眠不作普通击杀，因此不复制一个永久地标层到强夺者身上。

### 攻击、治疗和装备

±伤害模式对友方可致死并给己方人头；治疗模式使用标注的固定治疗量，不把攻击增益换成额外治疗。法力之泉为固定治疗20，即使沉默仍不把印刷负攻击转为伤害。反射只累加真正扣除的血量，不算免疫、过量伤害或更早全局回合；治疗攻击不发伤害附包。

强杀、法力之泉修改每份伤害，不修改攻击属性；免伤/反制仍逐包判定。法力之泉增幅作用于己方伤害法术和法师伤害技能，不把法师普通攻击一概当技能。多个有效来源可叠加。YYF/普通10拒绝友方单位提供的攻击增益（含举旗、至圣先师），并非免疫独立的心灵之火法术；法力之泉的固定治疗不会被心灵之火改写。

CX策反沿用“攻击本身造成实际正伤害、目标仍在场且通过保护”的规则；神龛身份不受策反。额外召唤与策反分别独立掷骰；前一判定的失败不会吞掉后一判定。先攻在合法攻击完成后判定额外完整操作，不能在选到非法目标时提前掷骰。

举旗的“所有友方棋子”包括自身及其他友方地标，不包括冰冻中立单位。部署/恢复光环时增加当前和最大生命，撤回时仅降最大生命，允许暂时出现HP高于上限，不能用通用clamp偷偷扣血。金晔只在**部署**其上触发，移动经过不重复触发；已冲锋者是两次完整操作而非两发攻击。

装备替换不算死亡返还。铁吊/BW返还及强夺转移保留卡牌身份；BW击杀资格绑定本次装备期间，不能随武器转移给新主人。负生命上限武器不能把装备者上限降到0。BW附包按该次命中之前缺失血量计算，不拿首包伤害重新扩大。胡桃木手杖按“击中者”解释，治疗命中也会施加减攻；在施放方下一个实际己方回合开始时失效，按全局回合记录，不受冲锋号令提前。

### 时钟与玉碎

“上一个己方回合时”选取为该回合**开始完成结算后的快照**，包括位置、归属、生命、装备、临时状态、个人时钟、行动及技能使用记录。时钟在储存期间也保存所需的最近两份快照，延后启用仍可恢复已记录状态。只影响当前存活非神龛棋子，不复活已离场者，不恢复整盘的人头、手牌、全局危险区或他人动作。旧位置被占/不合法，或旧神龛武器已经转移到另一持有者时拒绝，不消耗次数，不能复制实体武器。

对没有旧快照的敌方新召唤棋子恢复其初始模板，清除额外武器和buff；不能据此给己方新召唤者免费刷新。可刷新原本一次性技能与上次可行动状态，但不能借此刷新玩家光环次数或真实全局回合。恢复后仍受当前棋盘光环与合法占位约束。

玉碎按随从印刷编号及变体同编号判断奇偶，未编号合成物没有奇偶；神龛中有编号的随从也可符合。自杀本身不产生人头，对敌方造成伤害后正常计算其死亡人头；保留原有合法亡语/死亡反应。伤害先用自杀前的攻击和当前HP计算，再向上取整到5的倍数。

牢千K沿用2.5非武器合成的**场上3名友方材料**规则；合成移除不是死亡，不给人头/亡语，不继承装备或强化，也不消耗常驻召唤。光环直接启用，不要求落点。材料不从储存手牌或已中立单位偷取。

## AI、存档与界面

三个难度共用暗选、入场、部署、地标目标、自杀、时钟、抽选、两种额外召唤与新合成候选；保留随机抽取、不使用光环及不合成的合法选择。能力评分与威胁预测增加永久光环、治疗支援、地标、独立蓄力及多来源概率。AI只得到公开白名单，不读取正式PRNG、完整Session或暗选的对方决定。随机模拟沿用精确概率边界与固定工作量预算，计划缓存仍在实际结果匹配时复用。

保留既有本地AI Worker/无Worker回退、取消、暂停、悔棋锚点。第0回合入场可能需要连续完成双方动作，不能把active当作唯一的人类/AI拥有者。UI使用现有卡牌、详情、选点、通知及native select，不引入第二套组件库；宽屏完整棋盘不被新的长卡牌撑出，手机可自然滚动。地标与随从的查看/攻击层有显式切换，不依赖鼠标悬停。

旧v2档缺省为经典模式，既有字段不清空；新增可选字段保存模式、暗选、光环、地标重建、实体武器身份、时钟快照及独立继承技能资源。导入结构校验和悔棋/重做覆盖这些字段。旧规则的回放文件不修改：2.5固定`ae797bf`，9月17反馈固定`9b6abdb`，9月15固定`1d31a7d`，9月7–8固定`3a856cf`。
